# E26：在 E24 审计外部数据上测试固定 shape 特征

## 预登记（拟合与查看 E26 分数之前）

问题是 E20 的 shape 字符特征在 E24 已审计外部数据下，是否能给当前固定融合带来新增收益。唯一主对照是 **E24 E0c 分支** 对 **E24 E0c 加 E20 shape 块**；另有将两路分别替换 E16 融合中 E0c 的固定对照。E24 原融合在相同 120 prompt、2,160 行、五个 prompt 分组折上的 BA 为 **0.425000**。不根据 E26 验证分数调整抽样、特征、权重或融合。

训练数据、250 个外部 prompt、合格行、各类权重、官方折与 E24 完全一致：使用 E24 锁定的 Prvsiyan v9 raw `split=new` 来源与审计清单；每个合格外部类别总权重 24，官方训练每类 96。脚本必须重新通过 E24 来源审计和训练文件 SHA 核验，并逐行比较选中外部清单与 E24 保存的 `selected_external.csv`。每折仅在该折 96 个官方训练 prompt 和相同外部行上拟合特征；验证 prompt 仅供预测与评分。E24 基线分数的 SHA-256 固定为 `845c657f03b761f7b8f62fc17a2da583b6ecfd5962d5be1ae6fe485e5a9c3575`。

唯一模型改动照搬 E20 已固定实现：原 E0c 的 word 1–2 gram、原文 char 3–5 gram、57 项 style 和 `LinearSVC(C=1, class_weight='balanced', dual=True, random_state=42)` 不变；增加 `re.sub(r'[^\W\d_]+', lambda m: 'X' if m[0].isupper() else 'x', text)` 的 shape char 2–6 gram TF-IDF，`lowercase=False`、`sublinear_tf=True`、`min_df=2`、`max_features=60000`、`dtype=float32`、`FeatureUnion` 权重 **0.5**。保持 E24 所有样本权重。拟合环境固定 Python 3.10.12、scikit-learn 1.7.2；限制 BLAS/OpenMP 线程，以 CPU 执行，不使用 GPU。

主融合不重新调参：E0c 或 E26 的 18 类 decision scores 逐行 z 标准化，加入固定 RoBERTa 行 z 分数和三个固定 ModernBERT seed 行 z 后的均值，取 argmax。先逐行复现 E16 与 E24 已保存 OOF 预测，再比较 E26。报告单路及融合的总 BA、五折、18 类召回、按 120 个 prompt 配对 bootstrap（20,000 次，seed 42）的 95% 区间、由错变对/由对变错计数和 CPU 时间。**只有**固定融合相对 E24 增益 ≥ **0.01**、至少 **4/5** 折不降、无类别召回下降 ≥ **0.05**，才晋级为主方案候选；任一失败则不替换 E24，也不就 E26 做 Kaggle 提交。若单路有收益而融合未过门槛，保留诊断，不临时搜索 shape 权重。

次要叠加检查预先固定**四格**，与[并行实验协议](parallel_experiments_2026-11-10.md)一致：① E24；② E24+E26 shape；③ E24+E25 B seed 42；④ E24+E26 shape+E25 B seed 42。四格都仅更换 E16 中指定的 E0c 或 ModernBERT seed 42 分数，使用上述等权 row-z 融合；报告四个总 BA 与④相对③的增量。不据此改门槛，也不凭次要结果选择发布模型。E25 seed 17 未完成前不使用其部分分数。E24 来源生成协议曾参考全量官方训练长度分布，且开发集已被多轮实验重复使用，因此本五折结果为探索性，不是独立泛化证明。此前 30 个 prompt 已用过，也不作为新的未见验证集。

脚本：`run_e26_shape_external.py`。输出目录只写 `outputs/e26_shape_external_fit/` 和 `outputs/e26_shape_external_analysis/`；不修改 E24/E25 产物或运行任务。
