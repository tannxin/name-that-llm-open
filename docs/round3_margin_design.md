# 第三轮第 3 项：训练折内选对的家族内 margin（预设方案）

## 为什么只做一次有边界的检验

E10 的 18 类 OOF 为 0.399537；多数错误落在家族正确、版本错误的情形。[类别配对诊断](pair_geometry_diagnostic.md)显示同题字符距离与互相混淆有关，但若干最易混版本对的差异方向一致性接近 120 个 prompt 的随机参考值。距离近说明难分，不说明提高其训练损失就一定能分开。E4 在 MiniLM 上加入两种 SupCon 都低于 CE 对照；[E11](e11_soft_experts.md)的两对软专家只把 E10 提高到 0.404167，prompt 配对区间跨零。这些结果使本项的预期收益较低，优先级低于 ModernBERT 稳定性和独立家族头。

E11 的具体目标对是在看过全开发集旧 OOF 混淆后确定的。本实验**不能沿用这些固定对**，再在同一 120 prompt 上把增益当成独立验证。此前的 pair geometry 也在全部 120 prompt 上拟合过字符词表，不能直接拿其距离或排名决定本实验的类别对或权重。

## 唯一预设候选

使用原 120 个开发 prompt 的同一五个外层折。对每个外层折 `k`：

1. 严格隔离 24 个外层验证 prompt；只在另 96 个外层训练 prompt 上，用**新拟合**的 E0c（字符/词 TF-IDF＋风格特征＋LinearSVC）做三折、按 prompt 分组的内层 OOF。每个内层模型的词表、特征缩放、分类器均只从其 64 个训练 prompt 拟合。所有 96 个内层 OOF 预测合并后，得到该外层训练数据的定向混淆矩阵。内层划分按排序后的 prompt ID 由固定 GroupKFold 生成；不得按内层得分选择超参数。
2. 在同家族且有至少两个精确标签的 **27 个无序类别对**中，按内层 OOF 的双向错分总数 `C(a→b)+C(b→a)` 排序；计数相同按官方 `LABELS` 的类别索引字典序决定。按此顺序贪心取 **2 个不共享标签的对**，遇到已选类别就跳过，保证每个目标样本只有一个伙伴。Qwen、Kimi 只有单类，不参加选对。这里不使用全开发集 E10/E11 OOF、全开发集 pair geometry、外层验证标签或外层验证文本。也不因外层折选出的对不同而手工改对。
3. 在该外层 96 个训练 prompt 上，从与 E2d-R 相同的 RoBERTa revision 和 seed 42 重新训练 12 轮。保留原 18 类加权交叉熵，只对真标签属于所选两对之一的训练样本增加固定间隔项：`L = CE18 + 0.1 × mean[relu(0.5 + z_partner − z_true)]`；平均只在 batch 中被选中类别的样本上计算，若本 batch 没有则该项为零。两对共用 `0.1` 权重和 `0.5` logit margin；它们在看外层 OOF 结果前锁定，**不按距离、混淆次数、类别或折再调权**。输出仍是 18 类 logits，无家族门控、无二元专家。
4. 仅在该外层 24 个 prompt 上预测，最后拼接五折 OOF。保存每折被选对、27 对内层双向混淆、内层划分/数据哈希和完整训练配置，以便审计选对过程。新模型的 `id,prompt_id,true_model,fold` 必须与 E2d-R/E0c 完全一致。固定 E10 融合规则为 E0c 与新 RoBERTa 的 18 类分数各自逐行 z 标准化后等权相加，不拟合温度或权重。

**特别注意：**现有 E10 OOF 不能当作第 1 步的“训练折内 OOF”。对某外层折而言，其他四折的旧 E10 模型训练时包含了当前外层验证 prompt，会把验证信息带入类别对选择。必须重新做上述内层交叉拟合。

## 对照、计算量与停止条件

仅比较一个新增候选与 E2d-R 直接 18 类模型（0.333796）及 E10 固定融合（0.399537），不同时试多种 `K`、margin、损失权重或类别对筛法。报告 pooled 18 类 balanced accuracy、五折差值、18 类召回、所选对的两个方向召回、家族正确率/家族内版本正确率，以及按 120 个 prompt 配对重采样的差值区间。还要记录非目标类别的召回变化，防止目标对得分上升只是从其他类挪来预测。

计算需求为 **15 次内层 E0c CPU 拟合＋5 次外层 RoBERTa GPU 拟合**，另加五折推理和对比；没有内层 RoBERTa 网格搜索。作为粗略参考，原 E2d-R 五折 RoBERTa 约 584 秒，E13 五折约 677 秒（单张 RTX 3090，均不含此方案的内层 E0c）；本项 GPU 阶段预计同一量级，CPU 内层耗时需实测。所有输出用新的目录，原 E10/E11/E4 文件不覆盖。

若前两项实验仍未给出稳定增益且 GPU/人工审计时间紧张，可**不运行**本项：E4、E11 及近随机的版本对方向一致性尚不足以支持大规模 margin 搜索。若运行，候选相对 E10 的 18 类融合分数不升、五折多数不升，或 target 提升伴随其他类别明显下降，就停止，不重训全量包或提交 Kaggle。即使小幅上升但 prompt 配对区间跨零，也只记录为探索性结果，不为此继续试权重或反复提交公榜。整个方案及对照受先前多轮开发集观察启发，训练折内选对能防止直接泄漏，却不能把这 120 prompt 变成全新的独立确认集；30 prompt 保留集不再用于调参。
