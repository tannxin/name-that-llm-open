# Name That LLM：下一轮优化路线

## 现有证据

官方指标是 18 类平均召回率（balanced accuracy）。开发集固定为 120 个 prompt、2,160 条回答、五折按 prompt 分组的折外预测；另外 30 个 prompt 的保留集已经使用一次，不再参与选择。当前正式提交对应的 E10（E0c 风格/TF-IDF 与 RoBERTa 逐行标准化分数等权融合）为 **0.399537 开发集 OOF**、**0.401 Kaggle 公榜**。公榜是隐藏测试的一部分，不等于最终私榜。详细分数见 [results.md](results.md)。

E15 把 ModernBERT-base 作为第三路固定等权分数，开发集 OOF 达 **0.407407**，比 E10 高 **0.007870**；按 120 个 prompt 配对 bootstrap 的 95% 区间为 **[-0.006481, +0.022222]**。五折中三折提高、一折持平、一折下降，增益尚不稳固，暂不重训全量模型或提交。详情见 [E15](e15_modernbert_base.md)。

误差集中在同家族版本：E10 的错误里约 59% 是家族判断正确、具体版本判断错误；例如 `gemini-3.7-flash → gemini-3.6-flash` 发生 51/120 次。硬式家族路由的 OOF 只有 0.3250；以叶类别分数汇总的家族辅助损失 E13 没有改善 E10 融合。DeBERTa-v3-base、512-token 冻结 Qwen 4B 也没有带来稳定增益。由此优先验证互补监督表示及版本判别，不再无目标地扩大冻结 embedding 清单。[误差分析](e10_error_analysis.md) · [E13](e13_family_aux.md) · [E14](e14_deberta_v3.md) · [Qwen 长度消融](e1_qwen4b_length.md)

## 按顺序执行

1. **验证 ModernBERT 增益能否跨随机种子重现。** 保留 E15 的模型 revision、五折 prompt 清单、训练参数和固定末轮评估，仅将训练随机种子改为 17、73；原 seed 42 作为已完成结果。分别比较单模型、E0c＋ModernBERT 双路、E0c＋RoBERTa＋ModernBERT 三路与 E10。三 seed 集成也预先固定：先对每个 ModernBERT seed 的 18 类分数逐行标准化，再平均这一路，最后与 E0c 和 RoBERTa 两路各等权相加。检查按 prompt 配对的差值区间、五折方向、18 类召回和同家族版本条件准确率。三个 seed 共用同一批 prompt，不能把它们算作独立样本。若新增两个 seed 均无收益，就停止这一路的全量打包。
2. **测试真正独立的软分层头。** 在原 RoBERTa 的 18 类头之外增加单独的 6 家族头，固定训练损失 `CE_18 + 0.2 × CE_6`；保持五折、输入长度、优化器、训练轮数和 seed 不变。正式推断仍直接取 18 类头，家族头作为辅助监督和诊断，不做硬路由。逐项比较单模型、E10 固定融合、家族正确率及家族内版本正确率。此设计不同于 E13 从 18 类 logits 汇总家族概率的损失，但 E13 的负结果要求我们谨慎看待小增益。[多头训练的相关研究](https://aclanthology.org/2025.emnlp-main.472/)只提供方法动机，不能当作本赛效果证据。
3. **随后才考虑针对版本混淆的训练。** 先用每个外层训练折内部的 prompt 分组验证选择易混对和强度，再在外层验证折评价小权重的成对 margin 或软专家；不能从全部开发 OOF 的错误里选类别对、调权重，又在同一批 OOF 上报告改进。E4 的同题 SupCon 和 E11 的软专家此前未显示稳定改善，成对距离诊断也不支持“输出越相似就直接提高损失权重”的通用规则。[成对距离诊断](pair_geometry_diagnostic.md) · [E4](e4_prompt_contrastive.md) · [E11](e11_soft_experts.md)
4. **审计数据，再做轻量增强。** 对长回答可单独试随机连续段落裁剪，保留至少 40 个词，对照不增强训练并按回答长度及类别检查。避免将改写模型生成的文字直接当同一作者风格样本；[原始研究](https://aclanthology.org/2024.acl-long.357/)指出改写会改变可归因的风格。外部训练数据只有在逐行真实服务模型、路由记录、许可、近重复及 18 类覆盖都核实后才加入；现有 212k 开放池未通过来源审计。[E12 审计](e12_external_data.md)

## 晋级与提交

所有候选继续使用相同 120 个开发 prompt 的五折 GroupKFold，主指标为 18 类平均召回率。报告 pooled OOF、每折变化、逐类召回、家族内版本正确率和以 prompt 为单位的配对 bootstrap；明确多轮选模造成的乐观偏差。只有在预先固定方案后出现跨种子与多数折一致、且没有严重类别召回倒退的收益时，才全量训练、完成 Kaggle 断网 Notebook 的约 4,000 行模拟推理与九小时约束检查，然后提交一次作为外部验证。30 个保留 prompt 和 Kaggle 公榜都不用于反复选参。

下一步直接执行第 1 项；若失败，第 2 项是结构性替代，之后再决定是否值得投入更大模型或来源可靠的新数据。

2. E17 独立家族头固定融合为 **0.398611**，低于 E10；按预定规则停止。[结果](round3_two_head_family.md)
3. E18 在每个外层训练折内做三折 E0c OOF 选对，固定 margin 融合为 **0.402315**；五折仅两折改善，配对区间跨零，目标对召回没有提升；停止。[预设](round3_margin_design.md) · [结果](round3_margin_results.md)
4. E19 审计发现全部回答只有一个按空行划分的段落，故按预定替代规则只对训练折使用连续完整句窗裁剪。固定融合为 **0.403704**；两折下降、配对区间跨零，停止，不做第二种子或全量训练。[审计与预设](round3_crop_design.md) · [结果](round3_crop_results.md)

后补结果不更改上文的候选定义或晋级门槛；已使用过的 30 个保留 prompt 没有参与本轮选模。
