# E30 attention backend comparison on one RTX 3090

On November 18, 2026, we ran the locked E30 fold-1 checkpoint twice on the same 12 training texts. The default forward reproduced the archived 3090 outputs exactly. Forcing PyTorch’s math implementation of scaled dot-product attention (SDPA) changed both the pooled representations and the classifier logits.

| Comparison | Largest absolute difference in pooled values | Largest absolute difference in raw logits |
| --- | ---: | ---: |
| Default vs. archived default on the same 3090 | 0 | 0 |
| Default vs. forced math on the same 3090 | 0.1171875 | 0.01234323 |

The profiler recorded Flash attention for all 12 default forwards and math attention for all 12 forced forwards. Both runs used the same checked model and adapter files, tokens, pooling positions, classifier head and NF4 settings. The original absolute tolerance is 0.002 with zero relative tolerance. This experiment establishes that attention backend selection changes E30’s outputs on the 3090. Attribution of the previously observed T4 difference requires the paired T4 experiment. No accuracy or leaderboard score was measured.

The monitor recorded 215 resource samples over 1,105 seconds, with a maximum interval of 5.56 seconds. Peak observed GPU memory use was 7,982 MiB. Free local filesystem space fell at most 0.39 MiB from the first sample, and the GPU was released. The existing model was read from shared storage. The service account lacked access to the node eviction threshold and total pod ephemeral-storage usage, so the free-space observations describe this run only.
