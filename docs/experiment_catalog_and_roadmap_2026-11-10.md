# Name That LLM：实验总览、公开方案覆盖与后续路线

更新时间：2026-11-10（北京时间）。本文件是进度索引；精确配置、逐折结果和来源审计以链接的原始实验报告为准。

## 结论与成绩口径

**没有把别人的高分方案全部复现或优化一遍。** 我们已独立测试稀疏文本与风格特征、若干冻结和监督编码器、外部数据、层级分类、成对损失、多模型融合、排版证据、边际校正及分阶段解冻。公开高分方案中最重的部分——可审计的 18 类大规模外部数据、Qwen 系 8B 监督分类的完整五折、多层读出及大型异构集成——仍没有可比的完整实验。跨赛事启发的来源条件 token 似然也尚未验证。公开 Notebook 没有逐组件消融，不能把它的总成绩归因于某一个模块。

| --- | --- | ---: | --- |
| E7e-R | 开发集 OOF / Kaggle 公榜 | 0.3833 / 0.376 | E0c 与 RoBERTa 固定融合。 |
| E7e-R 留出检查 | 30 个 prompt、539 行，一次性检查 | 0.4005 | 已使用过，不能再作为新候选的独立留出集。 |

## 共同实验协议

官方训练集有 2,699 行、150 个 prompt、18 类。固定 30 个 prompt 作过一次留出检查；其余 120 个 prompt、2,160 行按 prompt 做五折 GroupKFold。下表未特别注明的数字均为这批开发集的 pooled OOF balanced accuracy。各折词表、标准化器、分类器和可学习融合器只用该折官方训练行及预先锁定的外部清单拟合；E24 的外部清单按独立外部 prompt 的固定规则选择，没有用验证折文本或标签挑行，但其来源生成协议曾参考完整官方训练长度统计。隐藏测试只有 `id,text`，不能假定测试时有 `prompt_id` 或每个 prompt 恰好覆盖 18 类。[原始实验记录](results.md) · [官方比赛说明](https://www.kaggle.com/competitions/name-that-llm/overview/description)
