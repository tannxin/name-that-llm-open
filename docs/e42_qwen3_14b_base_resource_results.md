物理 GPU1 在启动前连续空闲 600.1 秒，284 次采样没有计算进程；训练及推理期间守护器只观察到 E42 自己的 GPU1 进程。运行后 GPU1 已释放。资源脚本只使用固定折 1 的 1728 条训练回答训练一个 epoch，并把训练侧文本重复到 4000 条测试无标签推理吞吐。固定协议、数据、模型及依赖哈希均匹配，资源门槛 **7/7 通过**。

这只证明在一张 24 GiB RTX 3090 上可执行该资源探针。[NVIDIA T4](https://www.nvidia.com/content/dam/en-zz/Solutions/Data-Center/tesla-t4/t4-tensor-core-product-brief.pdf)每卡 16 GB；本次 17.20 GiB 的推理保留峰值高于单张 T4 的容量。若五折离线效果晋级，仍须在实际 Kaggle GPU 配额与离线、九小时限制下，验证双卡分片或其他预先审核的部署方法、完整约 4000 行推理及提交格式。当前没有 E42 五折 OOF、balanced accuracy 或 Kaggle 分数，也没有全量 adapter。模型权重、原始数据和逐行预测不入 Git。
