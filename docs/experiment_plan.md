# Name That LLM：实验计划（初稿）

## 任务与约束

- 官方训练集有 2,699 条回答、150 个 `prompt_id`；训练列为 `id,prompt_id,text,model`。隐藏测试集约 4,000 条，测试 prompt 不在训练集中，测试列仅有 `id,text`。[数据说明](https://www.kaggle.com/competitions/name-that-llm/data)
- 官方指标是 18 类的 balanced accuracy，即各类召回率的平均值。提交须由断网 Kaggle Notebook 在 9 小时内生成 `submission.parquet`。[比赛说明](https://www.kaggle.com/competitions/name-that-llm/overview/description)
- 本计划保留历史对话提出的 11 个 embedding 候选及冻结/微调两条路径；下述阶段次序用于控制验证偏差，不预先排除模型。

历史候选清单：`all-MiniLM-L6-v2`、`e5-base-v2`、`BGE-M3`、`mpnet-base`、`all-mpnet-base-v2`、`roberta-base`、`AnnaWegmann/Style-Embedding`、`Qwen3-Embedding-0.6B`、`Qwen3-Embedding-4B`、`Qwen3-Embedding-8B`、`LLM2Vec-Llama-3-8B`。这些是历史对话中的简称；下载前逐一核对仓库 ID、推荐输入格式和许可证。

## 共同评估协议

1. 先按 `prompt_id` 固定一组最终保留集；在剩余 prompt 上固定随机种子和五折划分。同一 prompt 的回答不可同时进入训练与验证。训练集变换器（TF-IDF、标准化器、聚类器、概率校准器等）每折仅在训练部分拟合。
2. 每折检查 18 类是否全部出现，并保存折号、样本 ID、真实标签、预测标签、分类分数。报告 pooled OOF balanced accuracy、每折得分、每类召回率、18×18 混淆矩阵和模型家族内混淆。
3. 预留一组约 30 个 prompt 作最终一次性检查，其余 prompt 用于开发阶段的五折比较。最终方案确定后才查看该保留集，并用全部 150 个 prompt 重训提交模型。
4. 对方法间差值按 prompt 组做配对 bootstrap，报告不确定性；模型选择不依赖少量 Kaggle 公榜提交。

## 实验次序

| 阶段 | 比较 | 主要问题 |
| --- | --- | --- |
| E0 | 字符/词 TF-IDF + 线性 SVM；增加独立的标点、排版、长度等风格特征对照 | 简单形式特征已经能解释多少可分性？ |
| E1 | 11 个候选的冻结表示 + 同一线性头 | 哪些预训练表示对作者指纹有效、互补？ |
| E2 | 11 个候选在相同分组协议下微调 | 任务监督带来多少增益？大型模型若采用 LoRA/量化，应与全参数微调明确区分。 |
| E3 | 官方训练数据 vs 可核实具体模型版本的公开外部问答 | 外部数据在未见 prompt 上是否有净收益？ |
| E4 | 普通分类、普通对比学习、同题异作者难负例对比 | 同题难负例是否改善家族内版本识别？ |
| E5 | 全文、全文加开头、全文加等长其他片段 | 开头是否提供超出额外 token 数量的信号？ |
| E6 | 直接合并外部数据监督微调、先继续预训练再用官方标签微调 | 继续预训练是否优于直接监督训练？ |
| E7 | 风格聚类、层次化家族/版本分类、候选融合 | 哪些互补信息能稳定改善 18 类指标？ |

E3–E7 的消融使用同一主干和同一划分，分别只改变一个因素。外部数据须记录下载地址、许可证、生成模型的**精确版本**、采样协议，并检查与官方训练/验证文本及 prompt 的重复或近重复。不能用仅标注模型家族的数据充当具体版本标签。

## 部署门槛

研究比较可在服务器的 3 张 RTX 3090 上进行；提交模型另需在 Kaggle 断网 Notebook 中完成整套推理。最终只打包验证有贡献且可在 9 小时内加载、预测约 4,000 条文本的模型及公开权重。输出前校验 `id` 唯一、无缺失、标签仅来自官方 18 类。

## 当前状态

训练服务器上已创建项目目录，并放入经过校验的官方 `data/train.csv`。E0 表面特征、E1 多个冻结编码器、E2 三个编码器的固定日程微调、E3 外部数据和 E7 融合已有开发集结果，详见 [results.md](results.md)。当前重点是修正并复核 RoBERTa 微调融合、完成较大编码器和同题难负例实验。30 个 prompt 的最终保留集仍未评分。
