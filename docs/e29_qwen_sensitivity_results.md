## 来源与审计

只取 [prvsiyan Extended Name That LLM Dataset v9](https://www.kaggle.com/datasets/prvsiyan/prvsiyans-extended-name-that-llm-dataset/version/9) 原始 `passages.csv` 的 `split=new`、`model=qwen3.8-max`。原始 CSV SHA-256 `393f300c7b521507a55f5a8793bd2256519ed6324da97153f8cd2b3503f01ce0`。**300 行/300 个提示全部通过**：行 ID 与 `call_id` 唯一；300 条原始 API envelope 逐一匹配；原请求和返回模型均为 `qwen/qwen3.8-max-0902`；OpenRouter 固定 `Alibaba` 服务商、禁回退；原请求提示、提示库模板及目标字数逐字匹配；原响应文本、服务商、模型、响应 ID、完成状态和 CSV 一致；HTTP 200、身份检查 `ok`、正常 stop，且未标记拒答/截断。`prompts.csv` 的提示许可为 CC BY 4.0，来源数据卡公开且标 CC BY 4.0。逐行审计脚本为 [`audit_e29_qwen.py`](../audit_e29_qwen.py)，机器报告在 `outputs/e29_qwen_audit/report.json`；300 行准入清单在 Git 忽略的 `data/external/prvsiyan/e29_qwen_accepted_manifest.csv`，SHA-256 `9108abd0a947a4f3d6a48096d0329387238bf793c77e7350c4f604ddd6b2f9cb`。

仅对原 120 个开发 prompt 的 **2,160 条官方回答文本**做近重复筛查，char-4 TF-IDF 最高余弦 **0.33255**；≥0.5、≥0.8、预设排除阈值 ≥0.9 均 **0 行**。300 个 `new` 提示与 120 个社区重构开发提示的词 1–2 gram 最高余弦 **0.09656**。旧 30 prompt 保留集不用于审计或选样；不读取来源的 `passages_clean`/funnel/已按完整官方训练集生成的相似度或风格筛选列。

[阿里云第一方文档](https://help.aliyun.com/en/model-studio/qwen3-8-max)将服务别名 `qwen3.8-max` 映射到 `qwen3.8-max-0902`，支持本次敏感性试验；[比赛标签页](https://www.kaggle.com/competitions/name-that-llm/overview/abstract)未披露目标生成时的真实快照、路由或 thinking/解码设置。**行级来源身份经过验证，并不等于比赛隐藏回答的身份已经证明。** 该来源的提示长度设计还参考过完整官方训练集，因此本次五折仍是探索性结果。

## 固定五折对照

复用 E24 的 250 个哈希选定提示；Qwen 300 条中恰好 **250 条**入选，不回填。E24 原 17 类 **3,620 行**不变，新方案外部共 **3,870 行/18 类**。每折官方训练每类 96 行、权重各 1；新增 Qwen 每行权重 `24/250=0.096`，总权重 24，与原 17 类各自的外部总权重 24 相同。训练只改 Qwen 行是否加入，E0c 特征、`LinearSVC` 参数、五折和融合权重不变。服务器原 Python 3.10.12/scikit-learn 1.7.2 重算的 **E24 2,160 行决策分数逐值完全一致**（五折最大绝对差 0），再拟合 E29。代码为 [`run_e29_qwen_sensitivity.py`](../run_e29_qwen_sensitivity.py)；输出保存在 Git 忽略的 `outputs/e29_qwen_fit/` 和 `outputs/e29_qwen_analysis/`，源文不上传。
