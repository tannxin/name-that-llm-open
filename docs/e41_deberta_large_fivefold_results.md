# E41：DeBERTa-v3-large 官方五折结果

**结论：No-go。** E41 完成预登记的官方开发集五折和独立审计，但固定加入 E24 后的 balanced accuracy 仅从 **0.425000** 升至 **0.431019**，增量 **+0.006019**，低于预定的 +0.01；`gemini-3.8-flash` 召回下降 **0.116667**，也超过每类下降须小于 0.05 的门槛。五折中有 4/5 折不降，仍不能弥补另两项失败。停止该配方的全量训练和 Kaggle 提交，不据此扫描融合权重或改训练日程。

## 固定实验和完整性

以 [E14 DeBERTa-v3-base](e14_deberta_v3.md) 为单因素对照，只把骨干换成 `microsoft/deberta-v3-large` 固定 revision `64a8c8eab3e352a784c658aef62be1662607476f`。沿用 [E41 预登记](e41_deberta_v3_large_preregistration.md) 的 256 tokens、12 epoch、原损失/学习率/优化器、五折 GroupKFold 和最终 epoch 验证。五折分别独立训练；独立审计核对了 2,160 个唯一折外 ID、120 个开发 prompt、每折 432 行/24 个互斥验证 prompt、18 个有限 logit、模型/数据/脚本哈希，以及 30 个未进入训练或评估的保留 prompt。

| 开发集折外指标 | Balanced accuracy |
| --- | ---: |
| E14 base 单路，诊断对照 | 0.312963 |
| E41 large 单路 | 0.352315 |
| 已归档 E24 固定三路融合 | 0.425000 |
| E24 + 1 × E41 行内 z 标准化分数 | 0.431019 |

E24 分数由已归档的 E24 E0c、RoBERTa 和三个 ModernBERT 种子逐行重建，先分别在 18 类上做行内 z 标准化，再对三个 ModernBERT 种子取均值；重建预测与归档 E24 的 2,160 行完全一致。E41 固定系数为 1；没有用本次分数选择系数。

融合使 135 行由错变对、122 行由对变错。最差类别为 `gemini-3.8-flash`，召回 **0.316667→0.200000**；其次 `kimi-k3` 下降 0.091667、`claude-sonnet-5` 下降 0.075000。以 prompt 为单位配对抽样 20,000 次、seed 42，融合增量的 95% bootstrap 区间为 **[−0.007870，+0.019907]**。全部 18 类的支持数、召回和增量见[聚合审计 JSON](e41_deberta_large_fivefold_audit_aggregate.json)。

五折都跑满 12 epoch；每折 1,296 次计划更新中有 1,293 次成功。最大训练 reserved 显存 **19.88 GiB**，低于服务器预登记的 22 GiB 门槛；五折训练合计约 **38.48 分钟**。此前首个资源探针因脚本误加严格的非有限梯度中止，没有计算验证分数；修正版只恢复 E14 原有裁剪行为，五项[资源门槛](e41_deberta_v3_large_resource_results.md)均通过，失败事实仍保留。服务器通过不证明 Kaggle 硬件或隐藏集推理资源可行。
