# E30：Qwen3-Embedding-8B 官方数据五折结果与独立审计

审计日期：2026-11-11。E30-A 的[预登记设计与 v3 配置](e30_supervised_embedding8b_design.md)固定了官方开发集的五折 GroupKFold、Qwen3-Embedding-8B 官方 revision、最后一层末位池化、3 epoch 普通交叉熵，以及在 E24 固定融合上加入 **1.0 × 逐行标准化 E30 logits**。本页是已完成的开发集 OOF 审计，不是 Kaggle 成绩。未重新训练、未读取保留集或测试回答、未调整融合权重或晋级门槛。

审计使用 Git 忽略的本地小型 CSV/JSON 快照。公开的[独立核对脚本](../audit_e30_fivefold_results.py)重算每项结果，只输出[聚合 JSON](e30_embedding8b_fivefold_audit_aggregate.json)；逐行 OOF、训练数据、adapter、模型权重均不纳入 Git。

## 协议、数据与产物

- 服务器 v3 协议锁 SHA-256 为 `7d6abc27b606dad9247e9cd0668c27fd5efe5af291f537bce6dcfd72279731cf`。锁内配置和训练脚本 SHA-256 与本地逐字节相同；五份运行记录均指向同一配置、锁、资源报告、官方模型 revision 和软件版本。服务器上的 **9 个模型必需文件**又由审计单独重算 SHA-256，全部等于预先核对的官方哈希，其中包括四个权重分片。
- 五折 OOF 各有 **432 个唯一 ID、24 个验证 prompt**，合并恰覆盖 E0 锁定的 **2,160 行、120 个开发 prompt、18 类各 120 行**。行 ID、`prompt_id`、真值与折号均逐行匹配 E0；五折验证 prompt 互斥，汇总 OOF 与各折拼接结果一致。折运行记录每折训练侧 **1,728 行、96 prompt**，验证只在第 3 epoch 结束后推理。训练侧隔离由哈希锁定的代码和运行元数据支持；产物没有逐训练步的数据清单，因而不能仅凭 OOF 文件重新证明每一步的输入。
- 五折均完成固定的 3 epoch；各折计划 648 次优化器更新，实际完成 **644–645 次**，比例为 99.38%–99.54%。训练损失有限，OOF 的 18 类 logits 全部有限；保存的单路预测等于 logits `argmax`。独立重算的逐折、逐类、混淆矩阵和错对互换数与服务器报告一致。元数据为 `no_epoch_or_threshold_selection=true`、`holdout_evaluated=false`。
- E24 的原始 E0c、RoBERTa、三 seed ModernBERT 分数及归档 OOF 哈希全部匹配；按已锁定的逐行 z 规则重算后，**2,160 个 E24 预测逐行完全一致**，BA 为 **0.425000**。E30 只加入预定的 1.0 权重，没有扫温度、偏置或阈值。

## 资源与提交边界

服务器资源测试在折 1 训练侧用 1 epoch、4,000 行无标签代理文本完成：训练 **1,099.66 秒**，推理 **590.59 秒**；训练与推理峰值保留显存分别 **8.00/14.53 GiB**；完成 **214/216** 次优化器更新。独立复核各项均低于 v3 预设上限，资源门槛通过。五折实际训练墙钟合计约 **4.49 小时**，单折约 53.6–54.4 分钟；最大验证峰值保留显存 **14.53 GiB**。

这些计时来自服务器 RTX 3090 和单 adapter 代理输入，尚未证明 Kaggle 隐藏 GPU 的完整运行时间。E30 没有全量训练部署 adapter、没有完整 Kaggle 离线包复测，也没有 Kaggle 新提交；已确认的公榜成绩仍为 E24 的 **0.434**。E30-A 的保守晋级门槛未过，E36 也未过，因而目前不推进全量部署或提交。E30 开发集 **0.448611** 不能当作公榜成绩。
