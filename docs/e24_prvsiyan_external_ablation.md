# E24：Prvsiyan v9 原始外部回答的预登记消融

**状态：按先前固定协议执行完五折；低成本晋级门槛通过。** 本页先固定一次便宜的数据消融，不以其五折或 Kaggle 结果调整筛选、权重、融合系数。来源若未达到下列审计门槛，记为 No-go，脚本不运行。实验编号 E24 只用于区分已有 E20–E23 方法消融。

## 来源与纳入门槛

候选来源是公开的 [Prvsiyan Extended Name That LLM Dataset v9](https://www.kaggle.com/datasets/prvsiyan/prvsiyans-extended-name-that-llm-dataset/version/9) 原始 `passages.csv`，仅用 `split=new`。该文件本地 SHA-256 固定为 `393f300c7b521507a55f5a8793bd2256519ed6324da97153f8cd2b3503f01ce0`。逐行 `id`、`prompt_id`、目标 `model`、实际 `served_model_id`、`served_provider`、`provider_route`、`call_id` 和来源原始 envelope 必须一致；人工审计还须核实许可、公开免费可得性、重复/近重复及 prompt 来源。[来源审计](e24_prvsiyan_source_audit.md)及其机器报告 `outputs/e24_prvsiyan_audit/report.json` 已给出 `audit_passed=true`：原始 `new` 5,400 行与 13,213 条 envelope 中相应调用逐行关联，提示/请求模型、实际返回模型/服务商、回答及停止状态不一致数为 0；可接受清单 `data/external/prvsiyan/e24_accepted_manifest.csv` SHA-256 为 `99c1abc12b64c7a0b1bfada6393383c4353c776c69105cecf68bee7e08439a7a`，17 类 4,322 行。报告、清单与原 CSV 的 SHA 均由脚本核验后才拟合。原始生成数据和审计结果本地保存在 Git 忽略目录，不同步回答正文到仓库。

**排除** `passages_clean.csv`、`passes_funnel`、`passes_funnel_regen`、`max_shared_8grams_comp`、`match_weight`、`style_score`、`max_cos_train` 及其它依赖全量官方答案/提示的筛选列。来源的 `passages_clean.csv`/`passes_funnel` 曾用全部官方回答的 8-gram 重叠计算，不可进入五折训练。仅回显模型 slug、真实后端不明的 Kaggle proxy 记录排除；`qwen3.8-max` 的 `qwen/qwen3.8-max-0902` 与比赛目标快照对应关系未证实，也排除。其余类别必须有逐行精确版本和路由证据；不因类别名相同而推定实际服务版本一致。审计失败、清单不完整或未知路由时停止，不降格为已核实的正式数据。

即使上述审计通过，来源生成协议参考过**全部官方训练数据**的总体长度分布和家族长度现象。因此本实验五折 **仅为探索性开发集结果，不是完全独立的外部验证**；不能将提高归因于纯粹的新样本泛化。审计中的近重复检查比较了 5,400 条 raw `new` 回答和 2,160 条官方开发回答，char-4 TF-IDF 最大余弦 0.35484、≥0.5 的 0 条；也比较了 300 个新 prompt_body 与 120 个社区重构开发 prompt_body，词 1–2 gram 最大余弦 0.09656。该诊断只覆盖 120 个开发 prompt，且近重复阈值不能证明完全没有内容重叠。官方 30 个保留 prompt 在先前项目阶段已评估，不作新的未见集；Kaggle 公榜不用于选参。

## 抽样、权重与五折

先仅从原始 `passages.csv` 的 `split=new` 读取 300 个不同 `prompt_id`；对每个值计算 `SHA256("name-that-llm:e24:v1:seed42:" + prompt_id)`，按哈希升序（`prompt_id` 字典序作极端并列时的次级键）取前 **250 个外部 prompt**。选择不看类别完整度、回答质量、官方文本或官方标签。对审计通过清单中的每个类别，仅保留这 250 个 prompt 对应且唯一的一行；缺行不补位，任何 `(prompt_id, model)` 有重复则停止。这样各类别尽量共享外部 prompt，且每类最多 250 行。若某类别有 `n_c` 条，所有该类外部行赋 `sample_weight=24/n_c`，使其总样本权重恰为 24；无审计合格行的类别不加外部数据。每折官方训练侧仍为 96 行/类、权重各为 1，因此**有覆盖类别的类内外部/官方训练权重比为 24/96=0.25**。保留原 E0c 的 `class_weight='balanced'`，它同时作用于官方及外部同类行，不改变该类内部 0.25 比值；不同类别的总体惩罚会随原始行数变化。TF-IDF 的词表/IDF 和 style 标准化按训练行拟合，`sample_weight` 只传给 LinearSVC 损失，所以原始外部行对词表的影响不按 24 行等效缩减；这是本数据消融的解释边界。

复用 E0 已保存的 120 个开发 prompt / 2,160 行、五个 `prompt_id` 分组折。每折只用另外 96 个**官方训练 prompt** 的回答和上述固定外部清单拟合 E0c 原有词 1–2 gram、字符 3–5 gram、57 个 style 特征及 `LinearSVC(C=1, class_weight='balanced', dual=True, random_state=42)`；验证折 24 个官方 prompt 的文本和标签只作一次预测与评价。**外部选择全过程不读取官方验证文本、prompt 或标签**；不使用 `train_regen`、`new2` 或依据全量官方训练集生成的列。训练时不调用外层验证行拟合任何变换器。

## 唯一对照、报告与停止门槛

对照一：旧 E0c 单路 OOF 平均召回率 0.342593 与 E24 新 E0c。对照二：旧 E16 固定融合 0.409259 与将 E24 分数**只替换 E16 内原 E0c** 后的融合；RoBERTa、三个 ModernBERT seed 的 OOF 分数、逐行 z 标准化及等权规则不变。要求先逐行复现旧 E16 的 2,160 条预测，才计算新方案。

报告五折各自平均召回率与差值、18 类各自召回与差值、120 个官方开发 prompt 为单位的配对 bootstrap（20,000 次，seed 42）95% 区间、使用的外部 prompt/类别/路由/样本数量和来源 SHA。只有固定融合相对旧 E16 **至少 +0.01**、至少 **4/5 折不降**、**无任何类别召回下降 ≥0.05** 才晋级到多折神经训练；任一条件未达则停止该来源的扩大训练，不临时调节抽样或权重。小幅正增益和未校正多次实验的 bootstrap 区间不等同于独立泛化证明。

脚本：`run_e24_prvsiyan_external_ablation.py`。在服务器原 Python 3.10.12 / scikit-learn 1.7.2 环境执行 `fit`，再对保存分数执行 `analyze`。`fit` 在审计通过报告、清单与 raw CSV 哈希及逐行关键字段匹配前会拒绝运行。

## 2026-11-06 五折结果

服务器原环境为 Python 3.10.12、scikit-learn 1.7.2、NumPy 2.2.6、pandas 2.3.3。来源 CSV、审计清单、报告和脚本传到服务器后逐项 SHA-256 与本地相同；`fit` 重核了来源/清单/报告、官方训练文件 SHA、E0c 已保存分数与预测逐行一致，原 E0c BA **0.342593**。固定全局外部 prompt 哈希选出的 250 个 prompt 中，17 个合格类别共 **3,620 条**：Anthropic 1,250、OpenAI 825、Google 795、OpenRouter 750；Qwen 0 条。各类分别为 165–250 条，按 `24/n_c` 加权。完整逐类计数与实际抽样 prompt 哈希在本地 `outputs/e24_prvsiyan_fit/fit_metrics.json` 和 `selected_prompt_ids.csv`。其余来源数据、回答正文和拟合输出未上传 GitHub。
