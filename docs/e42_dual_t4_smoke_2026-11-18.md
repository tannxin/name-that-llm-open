# E42 passed the three-text dual-T4 deployment check

The Qwen3-14B-Base fold-1 classifier produced the same top-ranked class as its RTX 3090 reference for **all three fixed training texts** on two Kaggle Tesla T4 GPUs. The maximum absolute difference across the 54 raw classifier outputs was **0.03125**, within the preregistered tolerance of **0.05**. The run used the pinned Base revision `0b0bd3732e2c374d483664439ea334928b65f304`, the fold-1 adapter, the fixed 18-class head and 4-bit NF4 weights. [Deployment protocol](e42_t4_deployment_probe_plan.md)

| GPU | Decoder layers | Peak reserved VRAM | Minimum sampled free VRAM |
|---|---|---:|---:|
| T4 0 | 0–19, plus embeddings | 7.07 GiB | 7.37 GiB |
| T4 1 | 20–39, plus final normalization and classification head | 6.26 GiB | 8.18 GiB |

The placement check covered all 40 decoder layers, 280 quantized linear modules, the adapter and the classification head. It recorded one nonpersistent rotary-position buffer on the CPU. The inference worker reported **117.16 seconds** through model loading and **119.66 seconds** total, including the three forward passes. These timings begin inside the worker, after offline environment preparation.

The result establishes numerical agreement for this fixed smoke test. The separate five-fold evaluation measured balanced accuracy of **0.443519** for the frozen E24+E42 combination. The next deployment check runs both the E24 and E42 paths on 4,000 unlabeled proxy rows and verifies the output schema, per-card memory and the eight-hour joint limit under Kaggle's nine-hour ceiling. [Five-fold audit](e42_qwen3_14b_base_recovery2_fivefold_results.md)
