# E40：训练侧同题风格残差（预登记）

冻结于 E40 首次拟合与评分之前。假设不同提示会系统性改变长度、排版等风格量，导致模型身份信号被题目差异掩盖。E40 只在**训练折**利用已知 `prompt_id` 去掉每题的 57 维风格均值；验证与 Kaggle 推理都不使用提示 ID。这与 E38 在推理批次寻找同题近邻是不同路线。实验仅用官方 `train.csv` SHA-256 `40a22ce8d88c5f46feb4637a099db815bef5f713ffe53e89dbe1b7b21de77707` 的既有 120 prompt 五折，不读 30 prompt 保留集或测试回答。

每折固定使用原 [E0b 57 个风格特征](../run_style.py)，仅以该折 1,728 条训练回答拟合 `StandardScaler`。在标准化训练特征上按该折训练 `prompt_id` 求均值，逐行减去同题均值；拟合 `LinearSVC(C=1.0, class_weight="balanced", dual=False, max_iter=10000, random_state=42)`。验证行只用训练折 scaler 标准化，不减验证题目的均值。并行拟合一条完全相同、但训练时也不减同题均值的普通 E0b 风格对照。两路 18 类决策分数都按固定类别顺序保存。

固定候选为归档 E24 三路分数 `s` 加 **0.5 × [row_z(残差风格) − row_z(普通风格)]**。这个差分只检验训练侧去提示均值的变化；不根据 E38 或 E40 OOF 调 0.5 权重。必须先逐行复现归档 E24 BA **0.425000**。晋级需候选相对 E24 BA 至少 **+0.01**、至少 **4/5** 折不降、任何类别召回下降 **小于 0.05**，另报逐折、逐类和 20,000 次按 prompt 配对 bootstrap 区间。只跑这一组固定参数；若不通过，则 No-go，不反复扫残差比例或融合权重。

E40 是本地 CPU 单因素实验，可与 E39 Base 权重下载和 GPU 资源测试并行。即使晋级，也要重训全量风格模型并验证 Kaggle 只含 `id,text` 的推理和完整耗时；数据、权重、逐行 OOF 不进 Git。
