## 一次性留出集检查

在 120 个开发 prompt 上重新拟合固定的 E0c 与 12 轮 RoBERTa，再按预先选定的等权排名规则融合。30 个留出 prompt、539 行的 balanced accuracy：**融合 0.4005**、E0c 单模型 0.3483、RoBERTa 单模型 0.3802。融合的 0.4005 是一次性内部泛化估计，非 Kaggle 隐藏测试分数，也不是重新选择模型的依据。选择锁与完整混淆矩阵、逐类召回率保存在服务器的 `outputs/final/selection_lock.json` 和 `outputs/final/holdout_report.json`；二者均不纳入 Git。留出集报告写入后，流程禁止重复生成报告。按既定方案，之后另起训练，在全部 150 个 prompt、2,699 行上拟合了 `outputs/final/full_package`，用于隐藏测试推理；它没有被拿来重测留出集。

## 第二轮按顺序优化

第一步在原 E0c 上分别增加精确标点频率、封闭功能词 n-gram。两个候选的原规则融合分数分别为 0.3847、0.3875，对旧融合 0.3833 的差异都很小，按 prompt 配对 bootstrap 的 95% 区间均跨零；详情见 [E8 消融](e8_fingerprint_ablation.md)。原 E0c 和融合预测在实验服务器上逐行精确复现。服务器没有固定的离线 POS 模型，本轮没有把临时词性标注器混入单因素实验。

第二步核对原 RoBERTa tokenizer：开发集 2,160 条中有 256 条（11.85%）超过 256 tokens，512 tokens 可覆盖全部。只改长度为 512、保持五折与 12 轮配置重训后，单模型 OOF 为 0.3347，对 256 版本的差异仅 +0.0009；与 E0c 原规则融合为 0.3838。512 版本与 E0c 的逐行标准化融合为 0.3972，低于 256 版本的 0.3995，故暂不重训 512 的全量包。详见 [E9 长度审计](e9_length_ablation.md)。

第三步只改变两路 18 类分数的融合方式：每条回答内分别将 E0c 和修正 RoBERTa 的分数减均值、除标准差，再等权相加；不根据 OOF 标签拟合温度或权重。原 2,160 条固定折外数据上为 **0.3995**，旧等权排名为 0.3833，差值 +0.0162；五折中四折提高，120 prompt 配对 bootstrap 95% 区间为 [+0.0014, +0.0315]。该区间没有调整项目中多轮尝试造成的选择偏差，且从未用已锁定保留集为这个规则调参。详见 [E10 分数融合](e10_fusion_normalization.md)。

第四步只对 Gemini 3.7/3.8 Flash、GLM 5.3/Flash 两对同家族版本加入固定小权重软专家。E10 上的 OOF 从 0.3995 到 0.4042，但增益 +0.0046 的配对区间为 [-0.0023, +0.0111]，且版本对是根据同一开发集早期混淆选出的；不将该探索性增益视为稳定改善，详见 [E11 软专家](e11_soft_experts.md)。

第五步审计新近更新的外部汇总池及一个较小的原始来源。汇总池缺少逐行实际服务模型与路由记录；抽查的原始来源虽有路由字段，却只覆盖 17 类、缺少 `qwen3.8-max`，且部分代理回答未记录服务商。因此本轮未将其加入训练，也没有新的 E12 OOF 分数。该审计没有读取官方训练集或保留集；证据和未来可解锁条件见 [E12 外部数据审计](e12_external_data.md)。

E0c 相比 E0 提高 0.0616，五折均改善。按 120 个 prompt 分组做 20,000 次配对 bootstrap，增益的 95% 百分位区间为 **[0.0421, 0.0810]**（随机种子 42）。此区间衡量当前开发 prompt 上的差异；最终检查见上方留出集结果。E0c 的逐类结果显示 `claude-opus-4-6`、`gpt-6-astra`、`qwen3.8-max` 召回率提升较大，但 `claude-fable-5` 仍只有 0.033。风格特征定义和运行方式见 [style_baselines.md](style_baselines.md)。

E0c 对六个模型家族的整体准确率为 0.6667；在家族预测正确的样本中，具体版本准确率为 0.5139。硬式两级分类 E7a 的五折得分为 0.3102、0.3495、0.3681、0.2963、0.3009，均低于直接 18 类分类；这个结构暂不纳入候选融合。

对当前 E10 的 18 类预测，家族正确率为 0.7560，家族正确后的精确版本正确率为 0.5285，合计 0.3995。把 E7a 的家族预测作为 E10 的硬门控，开发 OOF 降至 0.3519；这说明家族层的误判会直接排除正确版本。E13 在 RoBERTa 的 18 类 logits 上加入家族辅助 CE，但仍直接输出 18 类分数。单模型 OOF 保持 0.3338，家族正确率从 0.7157 上升至 0.7241，家族正确条件下的版本正确率从 0.4664 降至 0.4610。按 E10 固定规则融合 E0c 后为 0.3972，相对 E10 的差值 -0.0023；120 prompt 配对 bootstrap 95% 区间 [-0.0139, 0.0093]。这一次软层级实验未显示可靠收益，不更换当前提交。

同题输出的开发集几何诊断计算了 153 对模型的字符与风格距离，并与 E10 的定向误判比较。最易混的 Gemini 3.6 Flash／3.7 Flash 共出现 70/240 次相互误判，字符距离平均位于同题 153 对中最接近的 17%。距离和误判有相关性，但不等于可分性或新损失的收益；详见 [类别配对诊断](pair_geometry_diagnostic.md)。冻结 Qwen 4B 的 512-token 消融也未获益：单模型 0.1907，固定加入 E10 的三路融合为 0.3852，低于原 E10；详见 [Qwen 长度消融](e1_qwen4b_length.md)。

两种新的监督编码器也按原 E2d-R 的 256-token、12 轮日程在相同五折上比较。DeBERTa-v3-base 单模型 0.3130，固定加入 E10 的三路融合 0.3968；ModernBERT-base 单模型 0.3301，与 E0c 双路融合 0.3898，均未超过 E10。E10 加入单个 ModernBERT 的固定三路融合为 0.4074，较 E10 高 0.0079，但按 120 prompt 配对 bootstrap 的 95% 区间 [-0.0065, 0.0222] 跨零。随后按预先固定的方案复核两个新增随机种子和三种子平均，见下节。检查点、依赖、逐折结果分别见 [DeBERTa 记录](e14_deberta_v3.md)、[ModernBERT 记录](e15_modernbert_base.md)。

E7b 在同一组 E0c 特征上使用 RBF SVC，固定比较 `C∈{1,10}` 与三种按各折训练距离中位数缩放的 gamma。最佳开发集 OOF 仅 0.3185，比 E0c 低 0.0241；六组都未超过线性模型。该方法的调参分数同样只用于选模，见 [rbf_surface.md](rbf_surface.md)。

E7c 使用 E0c 与冻结 RoBERTa 的同折折外分类分数，逐行把 18 类分数转为排名后等权求和，不按标签调融合权重。开发集 OOF 为 0.3509，比 E0c 高 0.0083；五折中三折提高、两折下降。按 prompt 配对 bootstrap 20,000 次，差值的 95% 百分位区间为 [-0.0079, 0.0250]。这只是探索性融合候选，尚无稳定增益证据。

E7d 沿用同一固定等权排名规则，把 E0c 与冻结原始 MPNet 融合，OOF 为 0.3574，比 E0c 高 0.0148。五折中四折改善、一折下降；按 prompt 配对 bootstrap 20,000 次，差值的 95% 百分位区间为 [0.0000, 0.0292]。区间下界恰为零附近，且连续比较多个融合模型会使开发集选模分数偏乐观，因此暂称为候选，不以此宣称泛化提升。融合的原始预测与分数见 `outputs/e7_blend_e0c_mpnet/`。

E7e 原运行使用同一等权排名规则融合 E0c 和 12 轮微调 RoBERTa，OOF 为 0.3843，比 E0c 高 0.0417；五折均提高。120 prompt、20,000 次配对 bootstrap 的差值区间为 [0.0255, 0.0574]。原 RoBERTa 训练出现少量 fp16 优化器跳步而学习率仍推进的情况，因此用修正调度器的独立重跑结果重新评估候选。E7e-R 保持完全相同的融合规则，OOF 为 **0.3833**，比 E0c 高 **0.0407**，五折为 0.3727、0.3819、0.4329、0.3542、0.3750，分别均高于 E0c 的对应折。按 120 个 prompt 配对 bootstrap 20,000 次，差值的 95% 百分位区间为 **[0.0250, 0.0560]**。E7e-R 比原 E7e 低 0.0009，两次融合的配对差值区间为 [-0.0111, 0.0088]。这些区间未计入多个候选选最高者的偏差；仍只作为开发集选模证据。修正重跑的预测及比较结果见 `outputs/e7_blend_e0c_roberta_ft_scalerfix/`。

E7f 将 E0c 与微调原始 MPNet 融合，OOF 为 0.3657，五折均提高；对 E0c 的差值为 +0.0231，配对 bootstrap 区间 [0.0056, 0.0407]。这说明微调 MPNet 有互补信息，但它的仓库许可证未标明，且开发分数弱于 E7e，现阶段不是优先提交方案。

E0d 预先限定 `C∈{0.25,1,4}`、风格块权重 `∈{0.5,1,2}`，共 9 组。`C=1`、权重 `0.5` 在开发集 OOF 达到 0.3472；原配置 `C=1`、权重 `1` 被精确复现为 0.3426。最佳配置只高 0.0046，按 prompt 配对 bootstrap 的 95% 百分位区间为 [-0.0046, 0.0139]，未形成稳定证据；九选一的最高开发分数还存在选择乐观偏差。暂保留 E0c 原配置作为表面特征参照，完整网格见 `outputs/e0c_fixed_grid/grid_results.csv`。

首轮 MiniLM、E5、all-mpnet 冻结表示与 MiniLM 微调结果都低于文本表面特征。E2a 微调配置为 256 tokens、batch 16、编码器学习率 2e-5、分类头 1e-3、逆频率加权交叉熵，固定第 3 轮评估，五折得分为 0.1389、0.1412、0.1296、0.1296、0.1204。训练损失约从 2.89 降到 2.66。去掉 L2 并固定训练 5 轮的 E2b 提高到 0.2097，五折得分 0.1968、0.2199、0.2153、0.2083、0.2083。固定 12 轮的 E2c 达到 0.2866，五折得分 0.2940、0.2778、0.3032、0.2894、0.2685，平均训练损失降至 1.33。E2c 仍比 E0c 低 0.0560；按 prompt 配对 bootstrap 10,000 次，差值的 95% 百分位区间为 [-0.0778, -0.0338]。因此暂时停止这条 MiniLM 日程调参线。冻结 MiniLM 与 all-mpnet 各有 265/2,160 条、E5 有 276/2,160 条开发回答在 256 tokens 处被截断；E5 提高到 512 tokens 后无截断，分数增加 0.0120，仍明显低于 E0c。

E2d 原始 RoBERTa 微调在同一固定 12 轮日程下为 0.3250，五折分别为 0.3079、0.3032、0.3380、0.3264、0.3495。相比 E0c 的差值为 -0.0176，120 个 prompt 的配对 bootstrap 95% 区间为 [-0.0412, 0.0056]。训练损失持续下降到约 0.18；部分折起始阶段 fp16 梯度缩放器跳过优化器更新，但学习率调度器仍前进。E2d-R 修正为调度器只在优化器实际更新后推进，其他训练配置与随机种子保持一致，独立重跑的 OOF 为 **0.3338**；五折分别为 0.3194、0.2894、0.3611、0.3495、0.3495。相对原运行增加 0.0088，按 prompt 配对 bootstrap 的差值区间为 [-0.0042, 0.0218]，不足以单独断言修正改善了模型。各折仍记录 4–6 次混合精度优化器跳步，修正的行为是保持这些步的学习率不变。配置和折外预测见 `outputs/e2_finetune/roberta_base_meanpool_12ep_scalerfix/`。
E2e 原始 MPNet 的 12 轮全参数微调为 0.2949，五折为 0.2616、0.2940、0.3380、0.2870、0.2940。它比冻结 MPNet 高 0.0120，但仍比 E0c 低 0.0477。运行记录没有观察到优化器跳步警告，完整配置见 [e2_mpnet.md](e2_mpnet.md)。

E3 初审见 [e3_public_data_access.md](e3_public_data_access.md)。Will Rice v5 的 10,772 行中，仅选服务商与实际模型 ID 均明确的 OpenAI 五类、GLM 两类和 Kimi 一类；Qwen 两个快照混标、Gemini 版本有来源疑问，均未进入 E3。纠正后的筛查只读取 120 个开发 prompt 的文本，不读取保留集，也不使用开发标签做相似度筛查；外部回答与任意开发回答的 char-4 TF-IDF 最高余弦相似度为 0.378，没有触发 0.90 的近重复过滤。每类按固定哈希抽 250 条，最终 2,000 条。两档预定外部权重的 OOF 分别为 0.3421、0.3292，未改善 0.3426 的官方基线。低权重配置改善了若干有外部样本的类，却降低了 Claude、Qwen 等缺外部样本类的召回。外部提示与官方隐藏提示的语义重叠仍无法直接核实，因此这轮只作为来源适配探索，不进入最终候选。早期一次筛查曾读取保留集文本和标签用于同标签近重复排查，未筛掉任何样本；该结果已废弃，现有 `outputs/e3_willrice/` 是开发集限定的重跑结果。E3 的正式重跑和开发集选模未使用保留集；最终方案的一次性检查见上方。

E4 在同一五折开发集上比较固定日程的 MiniLM 加权交叉熵、只用跨 prompt 负例的 SupCon，以及额外纳入 17 个同题难负例的 SupCon。每批取两个完整 prompt，共 36 条回答；每条回答有一个跨 prompt 同模型正例。三组 OOF 分别为 0.2810、0.2671、0.2750。后两组对 CE 的差值分别为 -0.0139、-0.0060；按 120 个 prompt 配对 bootstrap 20,000 次，95% 百分位区间分别为 [-0.0273, -0.0009]、[-0.0218, 0.0097]。加入同题难负例相对只用跨 prompt 负例提高 0.0079，但区间 [-0.0097, 0.0255] 跨零。三组逐行 ID、标签、prompt 和折号一致，30 个最终保留 prompt 未分词、训练或评分。跨 prompt 掩码是前两组出结果后补做的探索性对照；本轮未显示对比学习改善精确版本识别，详见 [e4_prompt_contrastive.md](e4_prompt_contrastive.md)。

## 第三轮按顺序验证

ModernBERT 的 seed 42、17、73 与 E10 固定三路融合分别达到 0.4074、0.4088、0.4074。三个 ModernBERT 分数先各自逐行标准化再平均成一路，最终与 E0c、RoBERTa 等权相加，开发 OOF 为 **0.4093**，比 E10 高 **0.0097**。五折有四折上升；120 个 prompt 配对 bootstrap 95% 区间 **[-0.0046, +0.0241]** 仍跨零，`gpt-5.6-luna` 的召回下降 7/120。三个种子的全量模型已在 2,699 行上训练，并通过独立重载与文件哈希核验；离线 4,000 行 CPU 端到端推理耗时 **83 分 24.582 秒**，输出格式、ID 顺序和标签检查通过。Kaggle 隐藏重跑成功，**公榜 0.407**，较 E10 公榜 **0.401** 高 **0.006**；私榜尚未知，不能把这一小幅提升解释为稳定泛化证明。详见 [三种子对照](e16_modernbert_seeds.md)、[全量打包](e16_modernbert_full_package.md)与[提交交接](e16_kaggle_handoff.md)。

独立 6 类家族头的 RoBERTa 单模型为 0.3264，E0c 固定融合为 0.3986，分别低于原单头 0.3338 和 E10 的 0.3995。训练折内选混淆对的家族内 margin 单模型为 0.3301，固定融合为 0.4023；融合只比 E10 高 0.0028，五折有三折下降，配对区间 **[-0.0079, +0.0134]** 跨零，目标对召回未改善。两条路线均按预设规则停止，不制作全量推理包。详情见[独立家族头](round3_two_head_family.md)与[类内 margin](round3_margin_results.md)。

长回答的句窗裁剪审计发现开发集 2,160 条回答均只有一个空行分段，于是按事先固定的完整句窗规则训练五折 RoBERTa。单模型为 0.3241，固定融合为 0.4037，较 E10 高 0.0042；第 3、5 折下降，prompt 配对区间 **[-0.0088, +0.0171]** 跨零。按预设停止，不做第二种子或全量重训。详见[裁剪设计](round3_crop_design.md)与[裁剪结果](round3_crop_results.md)。

公开方案启发的唯一预登记 shape 特征消融在原服务器环境精确复现 E0c 的全部折外分数。shape E0c 为 **0.3537**，高于旧 E0c 的 **0.3426**；只替换 E16 融合中的 E0c 后为 **0.4134**，比原 E16 的 **0.4093** 高 **0.0042**，按 prompt 配对的 95% 区间 **[-0.0028, +0.0111]** 跨零，低于预设 +0.01 融合晋级门槛。暂不替换主方案或新增 Kaggle 提交。详见[E20 实验报告](e20_shape_ablation.md)。

E21 在 E16 上加入固定家族软门控，五折 **0.4093→0.4102**，配对 prompt 95% 区间 **[-0.0116, +0.0130]**。只有 3/5 折不降，最差类召回下降 0.075；本地专家拟合使用 scikit-learn 1.5.2，原 E0c 使用 1.7.2。结果明显未达预设门槛，保留 E16 直接分类，详见[E21 实验报告](e21_soft_family_gate.md)。

E22 用训练折内估计的 17 个排版标记出现率，为低置信回答加固定小幅证据，五折 **0.4093→0.4102**，配对 prompt 95% 区间 **[-0.0028, +0.0046]**。仅净增 2/2160 行正确预测；官方训练 CSV 没有实际换行或反引号，行级 Markdown 标记基本无覆盖。未达预设 +0.01 门槛，详见[E22 实验报告](e22_layout_evidence.md)。

E23 只用每折无标签的 E16 预测分布做一次有界类别边际校正，五折 **0.4093→0.4130**，配对 prompt 95% 区间 **[0, +0.0074]**，五折均不降。增益 **+0.0037** 仍低于预设 +0.01 门槛，且验证折天然均衡、隐藏测试类别比例未知；本结果只作诊断，详见[E23 实验报告](e23_marginal_correction.md)。

E24 先对 [prvsiyan v9 原始 `new` 来源](e24_prvsiyan_source_audit.md)做完整 API envelope/路由审计，保守接受 17 类 4,322 行，固定 250 个外部 prompt 后入选五折的为 3,620 行；Qwen 快照不明，排除。每类外部总权重为该折官方训练权重的 0.25。E0c 单路 **0.3426→0.3727**；仅替换 E16 中 E0c 一路，固定融合 **0.4093→0.4250**，差值 **+0.0157**、120 prompt 配对区间 **[+0.0046, +0.0269]**。4/5 折不降，最差类 `glm-5.3-flash` −0.0417，满足预设低成本晋级门槛；来源生成协议参考过完整官方训练集的长度统计，所以这仍是探索性开发结果，需继续独立检验。详见[E24 五折报告](e24_prvsiyan_external_ablation.md)。
