### 连续句窗的离线覆盖模拟

预先固定一个裁剪算子：对 ≥120 词的文本，枚举**原文中连续、非完整全文的句子片段**，只保留词数处于原文 **65%–85%**、且至少 **40 词**的候选；使用原文子串以保留片段内部的标点和空白。候选为空则原样保留。审计时每条可裁剪回答用 `random.Random(int(SHA256("42:"+id)[:16],16))` 均匀抽取一个候选，仅用于估计覆盖，不是训练结果。

- **863/871（99.1%）** 条长回答有候选，即全开发集 **863/2,160（40.0%）** 可裁剪；8 条没有候选的长回答均被分句规则视为单句。候选数中位数 **4**。在训练中若每个 epoch 以固定概率 **0.5** 启用，预计约 **432/2,160（20.0%）** 条训练输入每轮被改变。
- 固定抽样后保留词数平均 **74.5%**，P5 **66.0%**、中位数 **74.2%**、P95 **83.9%**；裁后最少 **79 词**、中位数 **127 词**，因此这次模拟没有接近 40 词下限。
- 863 条可裁剪回答中，原文 **255** 条超过 256 tokens；抽样片段仅 **13** 条仍超过 256。裁后 token 中位数 **164**、P95 **234**。这只是输入长度变化，不能推断准确率会提高。
- 抽样片段保留首句 **363/863（42.1%）**、末句 **323/863（37.4%）**；**177/863（20.5%）** 同时失去首句和末句。答案开头、收尾、整体长度和篇章节奏可能正是模型版本线索。即使保留整句，裁剪仍可能改变可归因风格；这些是本实验的主要失真风险。

[E9 长度消融](e9_length_ablation.md)已证明：把 RoBERTa 上限从 256 提到 512，虽完整保留所有开发回答，但单模型 balanced accuracy 只由 **0.333796** 到 **0.334722**，固定 E10 逐行 z-score 融合反而由 **0.399537** 到 **0.397222**。因此本实验检验的是训练时随机上下文是否有正则化收益；“减少 256-token 截断”本身不构成预计涨分的证据。

## 固定的单因素对照

| 项目 | 对照 | 候选 |
| --- | --- | --- |
| 数据与验证 | 原 120 个开发 prompt、同一五折 GroupKFold | 完全相同 |
| 模型与输入 | E2d-R 的 RoBERTa revision、256 tokens、均值池化、18 类头 | 完全相同 |
| 训练 | 12 epochs、batch 16、seed 42、原学习率/类别权重/warmup/调度器/最终轮选择 | 完全相同 |
| 每轮样本数 | 每条训练回答使用一次原文 | 每条训练回答仍使用一次；仅训练折输入按下述固定算子替换 |
| 验证与融合 | 验证回答原文；与未变的 E0c OOF 分数逐行 z-score 等权相加 | 完全相同 |

唯一实验因素是**训练折**的句窗裁剪：每个 epoch 对 ≥120 词且有候选的回答，以 `p=0.5` 决定是否裁剪；若裁剪，均匀抽一个满足上文 65%–85% 与 ≥40 词条件的连续完整句片段。用独立于模型初始化和 DataLoader 洗牌的确定性随机流，例如 SHA-256 对 `(seed=42, fold, epoch, id, "crop")` 取种子，确保重跑相同、不会因增强改变原训练随机流。保留原回答 ID、标签、训练步数和类别权重。验证折、E0c 和最终推理**均不裁剪**。保留原文首尾/原文长度的影响通过逐类及长短分层误差检查，不额外调裁剪比例或概率。

预先记录每折实际裁剪次数、裁前/裁后词与 token 分布、低于 40 词的次数（必须为零）、超过 256 tokens 的裁后次数、每轮耗时及 OOF 行/折/标签哈希。抽查固定 ID 的片段边界是否因缩写、引号或列表标点被错误分句；若解析器无法稳定保留原文子串，先修实现错误，再按同一协议重跑，不据 OOF 调规则。

主比较是候选与原 **E10 = 0.399537** 的 pooled 18 类 balanced accuracy；同时报告 RoBERTa 单模型对原 **0.333796**、五折差值、18 类召回、同家族具体版本正确率，以及按 **120 个 prompt 配对**的 20,000 次 bootstrap 差值 95% 区间。另按原回答 <120/≥120 词、≤256/>256 tokens 分层报告正确率与样本数；分层结果只解释现象，不用于重选门槛。不要把同 prompt 的 18 条回答或多个随机种子当独立 bootstrap 单位。

**停止条件：**若候选 E10 pooled 分数没有提高、五折中至少两折下降、prompt 配对区间跨 0，或任一类别召回下降至少 **5 个百分点**，则不晋级，不在同一开发 OOF 上扫裁剪阈值、比例或概率。若全部通过，再用预先固定的第二随机种子做成对的“无裁剪/有裁剪”复核；只在第二种子同方向、且没有严重逐类退化时考虑全量训练和 Kaggle 断网推理。已用过一次的 30-prompt 保留集与 Kaggle 公榜均不参与这一步选参。
