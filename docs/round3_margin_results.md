# E18：训练折内选对的家族内 margin 结果

按[预设方案](round3_margin_design.md)只运行了一次候选。使用[训练和内层选择脚本](../run_within_family_margin.py)完成实验；[逐行对齐分析脚本](../analyze_round3_candidate.py)复现了 E10 保存的 2,160 条预测。选择阶段在五个外层训练集内分别做 3 折 E0c OOF，共 15 次新拟合、8,640 条内层 OOF，耗时 139.9 秒。训练前复核 SHA、外层训练 ID、内外层 prompt 隔离、由内层 OOF 重算选择计数；GPU1 单批前后向检查通过，五折训练耗时 573.6 秒。

**决策：不晋级。**预设的五折多数不升、prompt 配对区间跨零，以及目标对没有改善均触发停止。不扫描 margin 或 λ，不全量重训，不提交 Kaggle。先前多轮开发集观察仍使这次结果属于探索性比较。
