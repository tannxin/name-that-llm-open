# E37：CPU 来源条件四字符证据五折结果

**结论：预登记机制预检 No-go。** E37 在锁定协议后只运行了一次完整官方开发集五折。它是字符片段计数代理，不能代表神经 ATLAS 的效果。固定 E24+E37 主读出融合的 balanced accuracy 为 **0.398611**，低于原 E24 的 **0.425000**（差 **−0.026389**）。五折 **0/5** 不降，最差单类召回下降 **−0.116667**；三项继续门槛全部失败。停止这一计数代理，不进入据此启动的神经 ATLAS 资源试验，也不提交 Kaggle。

E24 对照的 OOF 仍属探索性证据：其外部回答生成协议曾参考完整官方训练集的长度统计。E37 自身的词表与类条件计数仅使用各折官方训练行。

## 效果

| 方案 | pooled OOF balanced accuracy |
| --- | ---: |
| E24 原固定融合 | 0.425000 |
| E37 逐片段截断证据单路（预登记主读出） | 0.250000 |
| E37 平均对数似然单路（仅诊断） | 0.261111 |
| E24 + 1.0 × row-z(E37 主读出) | 0.398611 |

主融合相对 E24 的五折差值依次为 **−0.037037、−0.006944、−0.050926、−0.013889、−0.023148**；按 120 prompt 配对 bootstrap 20,000 次、seed 42 的差值 95% 区间为 **[−0.039815, −0.012500]**。最差类为 `claude-sonnet-5`（−0.116667），另有多类超过预设 0.05 下降上限。该区间未校正此前多轮在同一开发集上的实验选择，不能当作独立泛化保证。

## 资源与解释边界

五折计算及写入 OOF 前的聚合阶段用时 **12.219 秒**，该阶段峰值进程 RSS **179,843,072 B**，每折 2.125–2.687 秒；均低于预登记的 3,600 秒、4 GiB、每折 900 秒门槛。未用 GPU，未训练或评分 30 prompt 留出集、测试集。CSV 读取器为按 `prompt_id` 筛开发行会短暂解析保留集所在行，但只保留开发行；锁中的 `holdout_text_loaded=false` 具体指**没有将保留集文本载入 E37 开发数据结构**，并非声称读入原始 CSV 时跳过了这些字节。五折训练词表各约 3.8 万四字符片段，验证 OOV 约 1.5%–2.3%。

这个负结果只说明**固定的四字符计数代理及其 1.0 权重融合**在本开发集无增益；不能证明真正以公开因果 LM 学习来源条件的 [ATLAS](https://arxiv.org/html/2610.19583v1) 无效。后者仍需要 18 个精确版本的可信训练样本和独立的训练、推理资源审计。当前不据单折或次读出调词表、平滑、温度、系数或训练数据。
