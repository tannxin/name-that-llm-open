# E38：软同题近邻校正结果（2026-11-11）

**结论：No-go。** 按[预登记协议](e38_soft_prompt_neighbors_preregistration.md)，完整验证批次将 E24 五折 OOF balanced accuracy 从 **0.425000** 提高到 **0.466204**（+0.041204），稀疏 1–8 条同题回答模拟为 **0.444907**（+0.019907）。完整批次五折均改善；但 `gemini-3.6-flash` 召回从 0.583333 降到 0.508333（**−0.075**），超过预定的单类下降须小于 0.05 的门槛。不能用这份 OOF 反向挑相似度阈值或校正系数来凑过线，也不据此训练全量模型或提交 Kaggle。

## 无标签检索预检

每折只在外层训练文本拟合词级 TF-IDF，对该折验证批次按余弦相似度检索。近邻选择没有读取模型标签或真实 `prompt_id`；真实提示 ID 只在映射落盘后用于审计与预设的稀疏 panel 模拟。完整批次的合格近邻中同题精度为 **1.000**，有近邻的回答比例为 **0.950**。稀疏 panel 重组后的有同题候选行 top-1 命中率 **0.810294**、合格近邻覆盖率 **0.813235**，均通过预定的 0.60/0.70 评分门槛；合格近邻中的同题精度 **0.990258**。这些是检索指标，不是模型分类准确率。
