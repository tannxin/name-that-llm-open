# E21：守恒家族概率的软门控

## 预登记设计（运行前，2026-11-06）

本实验只检验**家族内版本重排**。固定官方 120 个开发 prompt、2,160 行、原五个 `GroupKFold` 折和 E16 的三路直接 18 类融合；30 个已使用的保留 prompt 不进入拟合、评分或选参，不用 Kaggle 公榜选参数。E16 原始分数必须从 E0c、RoBERTa 与 ModernBERT seeds 42、17、73 的保存 OOF 逐行重新计算，并与 E16 保存的 2,160 个预测完全一致，否则停止。

六个预定家族为 GPT（5 类）、Gemini（4）、Claude（5）、Qwen（1）、GLM（2）、Kimi（1）。仅对四个多成员家族各自训练一个专家。每个外层折只取该家族在其他 96 个 prompt 的官方样本，拟合原 E0c 的词 1–2 gram、字符 3–5 gram、57 个风格特征及 balanced LinearSVC；词表、标准化、模型均不接触该折 24 个验证 prompt。每个家族在一个折内有 `96 × 家族类别数` 个训练样本。所有验证回答均由四个专家打分；专家只重排自己家族内的标签。

E16 融合矩阵为 `B = row_z(E0c) + row_z(RoBERTa) + mean(row_z(ModernBERT_seed42), row_z(seed17), row_z(seed73))`。定义 `p = softmax(B/3)`；除以 3 不改变 E16 的预测类别。对家族 `f` 中的类别 `j`，定义家族总量 `P_f = Σ_{j∈f} p_j`、原条件概率 `r_j = p_j/P_f`。把该家族专家的 LinearSVC 决策分数按**每行家族内部**减均值、除标准差后做 softmax，得到 `q_j`。二分类时，`decision_function` 的一个有符号 margin 依 `classes_` 展开为 `[-margin,+margin]` 再执行相同处理；零标准差时令 `q` 均匀。没有在验证标签上拟合温度或校准器。

固定唯一门控公式：`H_f = -Σ_{j∈f} r_j log(r_j) / log(K_f)`，`α_f = 0.25 H_f`，`p'_j = P_f [(1-α_f)r_j + α_f q_j]`。`K_f` 为该家族类别数。单成员 Qwen、Kimi 的 `p'_j=p_j`。熵越高表示原 E16 在该家族内越不确定，专家的混合比例越高；`0≤α_f≤0.25`。逐行核验 `Σ_{j∈f}p'_j=P_f` 与 `Σ_j p'_j=1`（浮点容差 `1e-12`）。主实验只有这一种专家配方、一个混合强度和一套门控公式，不扫参数、家族子集或阈值。

## 预定评价及晋级门槛

脚本 `run_e21_soft_family_gate.py` 先检查原训练 SHA、开发行、prompt/折隔离、各 OOF 文件的 `id,prompt_id,true_model,fold`、每类 120 行、每 prompt 18 类各一行、E16 精确逐行复现，再训练专家。保存专家家族内 OOF、门控前后 18 类预测、五折和 18 类召回、家族预测正确率、家族正确时版本正确率、各家族的条件版本正确率、错变对／对变错与按 120 prompt 配对重采样 20,000 次的 95% 区间。额外报告专家在**真实家族已知的诊断条件下**的版本正确率；它不是可部署的单独预测结果。输出目录独立为 `outputs/e21_soft_family_gate/`。

沿用下一轮计划的实用门槛：相对 E16 pooled balanced accuracy 增加至少 `0.01`，至少 4/5 折不下降，任何单类召回不下降 `≥0.05`，才考虑扩大或提交。配对 prompt 置信区间需要报告，其下界大于零会增强证据，但无法消除同一开发集多轮筛选的偏差。若未达门槛，本次仅留作诊断，不改当前 Kaggle 模型。E11 的两对专家、E13 家族辅助损失、E17 独立家族头及 E7a 硬分层均为已有失败对照，不能与 E21 混为一谈。

## 运行结果

上述方法和晋级门槛在运行前已写定；脚本一次性执行，未按结果修改 `0.25`、家族范围、温度或公式。E16 的 2,160 个预测从五份原始 OOF 分数逐行精确复现。训练数据 SHA-256 为 `40a22ce8d88c5f46feb4637a099db815bef5f713ffe53e89dbe1b7b21de77707`。本地拟合环境为 Python 3.12.4、scikit-learn 1.5.2；原 E0c 和 E20 服务器环境为 Python 3.10.12、scikit-learn 1.7.2，因而跨环境的专家系数可能有轻微数值差异。这是探索性固定配方诊断，若未来要纳入全量包，需在目标训练环境复核。

按 120 个 prompt 配对 bootstrap 20,000 次（seed 42），增益的 95% 百分位区间为 **[−0.011574, +0.012963]**。有 101 行由错变对、99 行由对变错，46 个 prompt 提高、35 个不变、39 个下降。概率守恒数值误差：单个家族最大 **2.22×10⁻¹⁶**，整行和为 1 的最大误差 **4.44×10⁻¹⁶**。虽然家族总概率守恒，最高叶标签的重排仍可改变被预测的家族：45 行从家族正确变错误，42 行反向变化。

家族内的诊断性版本正确率（只在**真实家族已知**时计算，并非可部署准确率）：GPT 0.4567→0.4550，Gemini 0.5104→0.5188，Claude 0.5417→0.5383，GLM 0.5458→0.5458。独立专家自身为 GPT 0.4200、Gemini 0.4854、Claude 0.4533、GLM 0.5750；主要专家对原 E16 并无一致优势。逐类变化中，`gpt-5.5` +0.0917、`gemini-3.8-flash` +0.0583、`glm-5.3` +0.0500，但 `gemini-3.6-flash` **−0.0750**，`gpt-5.6-luna` 和 `gpt-5.6-terra` 各 **−0.0583**。Qwen、Kimi 的家族概率未被修改，但由于其他家族内部最高类别的变动，它们的精确召回仍分别下降 0.0250、0.0167。完整 18 类表、家族表、五折表与逐行结果在 `outputs/e21_soft_family_gate/`。

**结论：No-go。** 增益远低于 +0.01，只有 3/5 折不降，且三类下降超过预定的 0.05 门槛；配对区间跨零。本次结果不支持把该软门控放进 Kaggle 推理包，也不再根据这批 OOF 结果调门控强度或只保留表现较好的家族。保留 E16 直接 18 类融合为对照。
