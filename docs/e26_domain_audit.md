# E26: E24 外部样本的来源与分布诊断

日期：2026-11-10。**这是只读诊断，没有新训练或验证分数。** 重算脚本为 [`analyze_e26_domain.py`](../analyze_e26_domain.py)，数值输出在 Git 忽略目录 `outputs/e26_domain_audit/summary.json`、`class_shift.csv`。脚本验证官方训练、prvsiyan v9 原始 CSV 与 E24 固定选中清单的 SHA，并只保留既定 120 个开发 prompt 的官方回答；未读取旧的 30 prompt 锁定保留集用于分析，也不以任何分布统计改动 E24 选样或权重。外部只读原始行的身份、文本、prompt 元数据；不读其依赖官方训练结果的 clean funnel 或相似度字段。

## 结论

E24 的外部回答在**整体字数**上接近官方开发集，但在部分足以影响风格分类器的格式/标点上有明显来源差异。这是 E24 在隐藏集上可能迁移不足的一个可检验风险，**不是隐藏测试已经发生漂移的证据**。本地 `data/test.csv` 只有 3 条 Notebook 预览示例；正式评分时约 4,000 条隐藏文本不在本地，不能据此估计隐藏集长度、题材或标签比例。[比赛数据说明](https://www.kaggle.com/competitions/name-that-llm/data)

| 特征 | 官方开发集：对应的 17 类，2,040 行/120 prompt | E24 固定外部：17 类，3,620 行/250 prompt |
| --- | ---: | ---: |
| 字数 p10 / 中位 / p90 | 49 / **102** / 206 | 49 / **99.5** / 207 |
| 每词字符数中位 | **6.60** | **6.14** |
| 含长破折号 `—` | **41.5%** | **55.8%** |
| 含分号 `;` | **39.4%** | **32.8%** |
| 含弯撇号 `’` | **20.2%** | **21.7%** |
| 含换行 | **0%** | **0.06%** |

整体比例会受外部各类 165–250 行不等的影响，因此还核对了各类内部的变化。最显著的是 Gemini：官方开发集中 Gemini 3.1/3.6/3.8 Flash 的回答均没有长破折号，Gemini 3.7 Flash 仅 **0.8%** 有；E24 外部对应比例分别为 **13.8% / 23.1% / 25.8% / 28.4%**。`gpt-6-astra` 为 **8.3% → 32.7%**，`kimi-k3` 为 **55.8% → 77.6%**。这些数值说明外部样本的某些格式指纹与官方分布不一致，可能来自提示模板、API 默认设置、后处理、服务版本或内容；当前诊断不能分辨原因。多数类别的字数中位差异较小，但 `claude-opus-5` 外部比官方少 **23** 词，`gpt-5.6-sol` 少 **16** 词，`claude-opus-4-8` 少 **15** 词。

外部 250 个提示的来源元数据：物理 53、生命科学 45、哲学 35、数学 31、创意写作 20、历史 20、计算机科学 14、心理 13、经济 11、其他 8；任务类型为解释概念 142、描述/叙述 75、观点论证 19、故事/小说 13、比较 1。官方只给匿名 `prompt_id` 与回答，未提供同一套主题/任务类型标注，不能从这两个表得出正式的题材比例差异。来源协议曾参考全部官方训练集的总体长度和家族长度现象，因此相似的字数分布不是完全独立的泛化证据。[E24 原始来源审计](e24_prvsiyan_source_audit.md)

## 来源与标签边界

E24 固定样本来自 [prvsiyan v9](https://www.kaggle.com/datasets/prvsiyan/prvsiyans-extended-name-that-llm-dataset/version/9) 原始 `split=new`，有原始 envelope、服务模型和路由核验；E24 审计准入 4,322 行/17 类，固定哈希抽取 250 prompt 后 3,620 行/17 类。Qwen 的 300 条 raw `new` 行只证实 `qwen/qwen3.8-max-0902` 这一服务快照，而 [比赛页面](https://www.kaggle.com/competitions/name-that-llm/overview/abstract) 只给 `qwen3.8-max` 别名，未给目标生成快照，因此它仍不能作为 E24 的精确标签。另一个 [Maniceet 公开数据卡](https://www.kaggle.com/maniceet/name-that-llm-openrouter-openai-generations) 只列出 5 条 Qwen 行，且说明其 `served_model` 在原始响应未保存时可能为空；该卡不足以填补目前的版本映射与数量缺口。Open Pool v15 主文件的来源筛选参考过全部官方训练回答/提示，不能作为严格五折的直接扩充来源。[原审计细节](e24_prvsiyan_source_audit.md)

## 后续可并行的动作

1. **无 GPU 的数据线：** 寻找不同提示写法、不同任务类型、可逐行核对响应模型 ID/服务商/路由及许可的独立公开来源；先核查与 E24、官方开发集的 prompt/回答近重复和版本，再决定是否训练。Qwen 需先解决目标快照映射，未知版本只能作单独敏感性分析。
2. **与模型线并行的稳健性诊断：** 若找到第二个独立来源，预先锁定“来源 A 训练、来源 B 验证”的来源外推测试，以及两来源加入时的逐类召回。只用当前同一来源的随机分割不能测其跨来源泛化。
3. **与 E24 融合前的门槛：** 若 E24 正式 Kaggle 分数低于预期，先检查外部/官方格式差异、各类召回和外部来源的提示设置；不要仅根据单次公榜调外部权重或逐类阈值。保留 E16 作为清晰对照，并用固定 prompt 分组五折、来源敏感性和完整隐藏运行时间决定是否叠加新分支。

**解释限制：** 这里的“官方开发集”只有 120 个既定 prompt；训练中的五折验证行会轮换，因此这份静态描述不能替代折内来源迁移评估。外部提示的目标字数由竞赛训练分布启发，标签仍可能有快照/服务配置差异。没有隐藏测试文本、真实 prompt 或逐类隐藏标签可供直接分布诊断。
