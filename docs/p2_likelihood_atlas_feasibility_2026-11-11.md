## 先厘清机制

| 路线 | 需要什么 | 对本赛的含义 |
| --- | --- | --- |
| 真实候选源模型似然 | 每个精确候选模型的逐 token 概率接口 | 18 类中有多个闭源版本，无法把 18 个真实生成器的概率当成现成可用特征。仅用公开 Qwen 权重不能代表 `qwen3.8-max` 或其余 17 类。 |
| 冻结代理模型似然统计 | 一份公开因果 LM，计算回答的困惑度、波动等，再由外层训练 prompt 拟合 18 类分类器 | 每条回答只需一次模型前向，属于**固定特征分类**，没有学习 18 个来源条件；它可测互补性，但不是 ATLAS。论文也将这类方法列为固定特征基线。 |
| ATLAS | 公开因果 LM、每来源学习的控制 embedding 与 LoRA、每来源逐 token 似然及截断式聚合 | 论文核心就是**来源条件 token 似然**，不是与之并列的另一方法。原论文预测五个**模型家族**，而本赛须分辨 18 个精确版本。论文 7B 实验使用四张 H100、每来源至少 1,000 条的规模测试；本赛固定开发折每精确类只有 96 条训练回答，不能转用论文分数或预训练的五家族 checkpoint。 |

原论文的分数是 $\ell_{k,t}=\log p(y_t\mid y_{<t},c_k)$，对每个候选条件 $k$、token $t$ 计算；主读出将相对竞争条件的证据逐 token 截断，再平均 $T\in\{1,2,4,8\}$。作者代码与模型卡证实需要完整的来源条件参数，普通 PEFT adapter 单独加载不足。作者 GitHub 仓库当前页面未展示 `LICENSE` 文件；开源 MIT 仓库只引用论文和仓库，不直接复制其源码。

## 已执行的 CPU 机制预检：来源条件四字符片段计数模型

**目的仅是低成本检查“逐局部单元的截断似然”能否带来与 E24 互补的信号；它不是神经 ATLAS 的复现，也不能据此估计神经 ATLAS 的性能。** 此模型给四字符片段赋类条件概率，并不估计真正的自回归 $p(c_t\mid c_{<t},k)$。不下载权重，不占 GPU2。使用现有官方 `data/train.csv` SHA-256 `40a22ce8d88c5f46feb4637a099db815bef5f713ffe53e89dbe1b7b21de77707` 和 E0 `outputs/e0_tfidf_svm/split_manifest.csv` SHA-256 `653c23b191b40086f7a0263a9baee1e519c0778de7bd0c721b23e1a9955ffd15`；只取 120 个开发 prompt、2,160 行，复用固定五折，每折训练 96 prompt / 1,728 行、验证 24 prompt / 432 行。30 prompt 留出集与 `test.csv` 均不参与筛选。所有来源条件、词表、平滑分母只由当折训练行拟合；不使用 E24 外部数据。

固定字符级方案：原始 Unicode 字符串不作大小写或空白归一化；每个连续四字符片段视为一个局部观察单元。仅在折内训练文本上建立频次最高的至多 100,000 个四字符片段词表，词表外合并到 OOV 桶。18 个类各拟合一个加一平滑的多项式模型，统一先验 $1/18$，即 $p(g\mid k)=(n_{k,g}+1)/(N_k+V+1)$，其中 $V$ 为折内词表大小；训练侧未进入词表的次数合并为 $n_{k,\mathrm{OOV}}$，故 $p(\mathrm{OOV}\mid k)=(n_{k,\mathrm{OOV}}+1)/(N_k+V+1)$。每条验证回答的每个片段在 18 个条件下都得到对数似然；主读出按论文固定 $T=1,2,4,8$ 的相对似然截断公式对片段求均值，次读出为各类平均对数似然。长度小于四字符或非有限分数直接报错。实现使用自定义逐字符分析器、`CountVectorizer`/稀疏计数与 NumPy；不根据单折分数改变阶数、平滑、词表上限或温度。完整公式和资源门槛以 E37 锁定文档为准。

五折产出与 E0 锁定的 `id,prompt_id,true_model,fold` 逐行对齐，报告单路 pooled balanced accuracy、逐折、18 类召回、120 prompt 配对 bootstrap 20,000 次区间。固定融合只在 E24 三路分数上**增加**主读出的一路逐行 z 标准化分数，系数固定 1.0；次读出只作机制诊断，不选优。先逐行复现 E24 已保存预测。若该 CPU 代理的主融合相对 E24 同时满足 BA 至少 +0.01、至少 4/5 折不降、任一类召回下降小于 0.05，才讨论神经条件模型的单卡资源预检；此门槛只允许进入下一研究阶段，不是 Kaggle 晋级。无论结果如何，都不拿已使用的 30 prompt 或公榜调参。

## 神经 ATLAS 后续资源门槛

E37 未出现互补信号，因此当前不启动神经 ATLAS 资源试验。若将来出现可信的 18 类训练数据和新的独立假设，须另预登记公开基座的**固定 revision**、18 条件结构、训练日程及独立 GPU 的单 epoch/128 条无标签推理资源试验。真实 18 类 ATLAS 每条回答至少要评价 18 个来源条件；以约 4,000 条隐藏测试计即约 72,000 次条件化回答评分，不能从 E28/E30 的一次分类前向时间推定其耗时，更不能视为已通过 Kaggle 9 小时、离线重载、显存与模型许可检查。GPU2 上 E30-B 运行期间不启动此试验。若模型许可或未授权的源码复制问题未解决，停止部署。
