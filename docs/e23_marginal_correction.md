# E23：温和的无标签类别边际校正

## 运行前预登记（2026-11-06）

本实验只改变 [E16](e16_modernbert_seeds.md) 已保存的五折 OOF 融合分数的后处理。开发集是官方训练集固定的 120 个 prompt、2,160 行，五个 `GroupKFold` 折各有 24 个验证 prompt、432 行。脚本须先从 E0c、RoBERTa、ModernBERT seeds 42/17/73 的原始 OOF 分数逐行重算 E16，和保存的 2,160 个预测完全一致，并核对训练 CSV SHA、ID、标签及折划分。30 个已使用的保留 prompt、Kaggle 公榜和隐藏测试标签均不参与本实验。

### 唯一规则

先按 E16 规则得到 `B = row_z(E0c) + row_z(RoBERTa) + mean(row_z(ModernBERT_42), row_z(ModernBERT_17), row_z(ModernBERT_73))`。以 `L=B/3` 作概率尺度；`argmax(L)` 与原 E16 预测完全一致。对**当前外层验证批次的全部 432 行，仅使用分数**计算 `p_ij=softmax(L_i)_j`，`m_j=mean_i p_ij`。设固定参考边际 `u_j=1/18`，类别位移

`d_j = -0.10 × clip(log(m_j/u_j), -1, +1)`，

最终 `L'_ij=L_ij+d_j`，预测为 `argmax_j L'_ij`。因此每个类别的 logit 位移绝对值最多 0.10，任意两类之间的 margin 变化最多 0.20。部署时用**整批无标签测试回答**按同一公式计算 `m_j`，只需要文本模型分数和批次边界，不要求测试 `prompt_id`。它不是硬性强制各类预测数相等；既不迭代，也不根据校正后的边际重新求 `d_j`。固定系数、截断和温度不按本轮验证标签选取，不扫参数，不与 E20/E21/E22 组合。

官方训练集每个 prompt 恰有 18 类各一行，所以把均匀 `u` 作为一个**弱参考先验**是可解释的，但隐藏测试集类别比例未知。验证折天然精确均衡，这会让向均匀拉回的收益显得乐观；即使本实验达到开发集门槛，也只能列为候选，部署前还须有独立证据支持测试边际接近均匀，或经预先设定的类别比例漂移检验。不得把真实验证折类别频率、真实 `prompt_id`、保留 prompt 或 Kaggle 分数用于计算 `m` 或 `d`。

### 输出与停止门槛

保存输入 SHA、逐行原/新预测、每折的无标签软预测边际、原/新硬预测类别边际、18 个类别位移、逐折和逐类召回、预测变更的错变对／对变错、位移幅度，以及按 120 个 prompt 配对重采样 20,000 次（seed 42）的 balanced accuracy 差值 95% 百分位区间。每折只调用仅接收该折 `L` 矩阵的校正函数；验证标签和 `prompt_id` 只用于事后核对和评价。输出到独立的 Git 忽略目录 `outputs/e23_marginal_correction/`。

沿用 [下一轮计划](next_round_plan_2026-11-06.md) 的固定融合实用门槛：pooled balanced accuracy 比 E16 至少提高 0.01，至少 4/5 折不降，任何单类召回下降小于 0.05；三项同时满足才考虑下一步，否则 **No-go**，不替换 E16、不提交 Kaggle，也不据此修改系数。配对区间须报告；同一开发集已试过多个候选，未经校正的区间不能消除多次筛选偏差。由于测试先验未知，达到以上开发集门槛也不等于可以直接部署。

**No-go。** 三项开发集门槛中，五折不降和最差类下降仅 1/120 均满足，但 **+0.003704 未达到 +0.01**。隐藏测试类别比例仍未知，验证折的精确均衡会偏向这种校正规则；因此保留本结果作为诊断，不替换 E16，不增加 Kaggle 提交，不依据本轮结果重选强度或截断。
