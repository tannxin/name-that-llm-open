# E19：连续句窗裁剪单因素实验结果

按[预设方案与输入审计](round3_crop_design.md)只运行了一个候选：长回答训练时以固定概率 0.5 换成原文连续完整句窗；验证折仍用原文。训练和裁剪实现分别见 [run_sentence_crop.py](../run_sentence_crop.py) 与 [sentence_crop.py](../sentence_crop.py)。候选与 E2d-R 相同的 RoBERTa revision、原五折、seed 42、12 epochs、256 tokens、batch 16、均值池化、学习率、类别权重和调度器；[对齐分析脚本](../analyze_round3_candidate.py)逐行复现了 E10 保存的 2,160 条融合预测。

## 执行审计与结论

开发集原文共 871 条 ≥120 词，其中 863 条有合法句窗，与预先审计一致。五折 × 12 轮共 103,680 次训练样本访问，其中有候选的 41,424 次，实际裁剪 **20,848 次**（占有候选访问的 50.33%，占全部访问的 20.11%）。每折实际裁剪 4,195 / 4,208 / 4,147 / 4,088 / 4,210 次。独立 CPU 审计重新计算了所有折、epoch、ID 的确定性裁剪决定，逐条匹配这 20,848 次记录，确认没有任何验证折 ID 被裁剪。裁后低于 40 词为 0；原来超过 256 tokens 的裁剪事件为 6,234，裁后仍超过的为 293。裁后平均保留原词数的 74.53%，最短 78 词。GPU1 单批前后向和原文验证编码不变检查通过；五折训练耗时 566.2 秒。

**决策：不晋级。**预设停止条件中的“至少两折融合下降”和“prompt 配对区间跨 0”均成立；因此不做第二随机种子复核，不扫描概率或句窗比例，不全量重训或提交 Kaggle。该 OOF 是经过多轮实验使用的开发集，只能作为探索性证据。
