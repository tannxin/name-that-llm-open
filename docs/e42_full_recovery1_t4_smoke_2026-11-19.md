# E42 全量模型通过 Kaggle 双 T4 一致性验证

2026 年 11 月 19 日，Kaggle 断网双 T4 加载了 E42 Recovery1 在全部 2,699 条官方样本上训练的 Qwen3-14B-Base adapter。三条固定训练文本在 T4 与 RTX 3090 上的首选类别全部一致。T4 验证程序逐条检查了 18 个有限分类分数，54 项比较中的最大绝对偏差为 **0.015625**，通过预设的绝对容差 **0.05**，相对容差为 0。[全量训练验收](e42_full_official_recovery1_results.md)

| 指标 | 实测值 |
|---|---:|
| Kaggle 整个 Notebook 耗时 | 719.2 秒 |
| GPU 验证程序耗时（含模型加载与三次推理） | 134.93 秒 |
| 两卡预留显存峰值 | 7.07 / 6.26 GiB |
| 两卡最低采样可用显存 | 7.37 / 8.18 GiB |

独立核验从该版本的输出取回了 3,625 字节的原始聚合报告，校对了全量权重、参考输出、模型版本、软件环境和两卡分层配置。报告 SHA-256 为 `671d7784851de0a11e72c83c80059df9440028511636654b101e7e80809b8e80`。T4 输出逐项比较在 GPU 验证程序内完成，归档报告保存最大偏差及首选类别一致性。

本次运行没有使用目标标签。此前 4,000 行部署验证使用第一折 adapter。全量模型在正式竞赛测试集上的结果仍待提交验证。现有公榜最佳为 E24+E39 的 **0.445**。[4,000 行部署验证](e42_dual_t4_full_deployment_2026-11-18.md)
