# E22：低置信软排版证据（运行前预登记）

本页的特征、估计方式、启用规则和晋级门槛在查看 E22 验证结果前锁定。对照是 [E16](e16_modernbert_seeds.md) 已保存的 120 个开发 prompt、2,160 行、五折 `GroupKFold` OOF；官方 30 个保留 prompt 和 Kaggle 测试集均不参与。实验只改变 E16 18 类融合分数的一个后处理项，不做类别边际校正、家族门控、外部数据训练或权重搜索。[E8](e8_fingerprint_ablation.md) 测过把精确标点**计数**拼接进 E0c；本实验测试的是训练折拟合的类别条件**出现证据**，应分别报告。

## 唯一固定规则

按下列顺序对每篇回答求 17 个二值标记，正则表达式用 Python `re.search`，`MULTILINE` 仅用于行首标记。标记为：

| 序号 | 名称 | 命中规则 |
| ---: | --- | --- |
| 1 | `ascii_double_quote` | `"` |
| 2 | `curly_double_quote` | `“` 或 `”` |
| 3 | `curly_single_quote` | `‘` 或 `’` |
| 4 | `long_dash` | `—` 或 `–` |
| 5 | `ellipsis` | `…` 或连续至少三个 `.` |
| 6 | `semicolon` | `;` |
| 7 | `colon` | `:` |
| 8 | `bullet_line` | 行首可有空格或制表符，随后 `-`、`*` 或 `•` 和至少一个空格或制表符 |
| 9 | `numbered_line` | 行首可有空格或制表符，随后数字、`.` 或 `)`、至少一个空格或制表符 |
| 10 | `heading_line` | 行首可有空格或制表符，随后 1–6 个 `#` 和至少一个空格或制表符 |
| 11 | `code_fence` | 连续三个反引号或波浪号 |
| 12 | `inline_backtick` | 不与其他反引号相邻的单个反引号 |
| 13 | `bold_marker` | 连续两个 `*` 或 `_` |
| 14 | `link_or_url` | Markdown `[文字](地址)` 链接或 `http://`／`https://` |
| 15 | `table_row` | 行首 `|` 且同一行后面至少还有两个 `|` |
| 16 | `blockquote_line` | 行首可有空格或制表符，随后 `>` 和至少一个空格或制表符 |
| 17 | `math_delimiter` | `\(`、`\[` 或同一行两个 `$` 包裹的非空内容 |

对每个外层折，只用其 **96 个训练 prompt** 的 1,728 行估计：全局出现率 `g_k=(sum_i x_ik+1)/(N+2)`；类别条件出现率 `theta_ck=(sum_{i:y_i=c} x_ik+48*g_k)/(N_c+48)`。所有类别在训练折各有 96 行。每条回答只对**出现的**标记求 `e_c = mean_{k:x_k=1} clip(log(theta_ck/g_k), -1.5, 1.5)`；未出现的标记不当作负证据。全局率、类别率均不接触当前折验证行。

先逐行标准化原 E0c、RoBERTa 和三个 ModernBERT seed 分数，将三个 seed 平均为一路，再把三路相加得到原 E16 分数 `B`。低置信度按 `softmax(B/3)` 最大概率 **小于 0.30** 固定判定。只有回答原文至少 **200 个 Unicode 字符**、至少 **2 种标记**出现且满足低置信时，改用 `B/3 + 0.20*e` 的 argmax；否则沿用原 E16 argmax。除以 3 只把原三路分数转成平均值，不改变原预测；`0.20`、三个启用阈值、先验有效样本量 `48`、证据截断 `±1.5` 均不根据验证标签调整。没有内层拟合或网格选择。

## 验证与停止条件

脚本必须先逐行**精确复现**已保存 E16 的 2,160 个预测和 `0.409259` balanced accuracy；核对训练 CSV SHA、五折样本 ID、标签、prompt 与分数文件一致，并断言训练和验证 prompt 无交集。保存输入 SHA、特征覆盖、启用行数、OOF 预测、逐折和逐类召回。对 E16 的差值用 120 个 prompt 为单位、20,000 次、seed 42 的配对 bootstrap 给 95% 百分位区间。

沿用 [下一轮计划](next_round_plan_2026-11-06.md) 的实用晋级门槛：固定融合 pooled balanced accuracy 至少比 E16 高 **0.01**；至少 **4/5 折**不下降；18 类中任何一类召回下降均 **小于 0.05**。三项同时成立才考虑全量拟合或 Kaggle 提交；否则只保留诊断。区间下界大于零会加强证据，但多轮候选使用同一开发集，未经校正的区间不能消除选择偏差。此次不以公榜、保留 prompt 或 E21/E20 结果改变规则。
